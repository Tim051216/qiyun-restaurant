## 📝 需要您手动完成的步骤

### 步骤 1: 更新 MCP 配置

打开文件: `C:/Users/Administrator/.kiro/settings/mcp.json`

将配置修改为:

```json
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"],
      "env": {},
      "disabled": true,
      "autoApprove": []
    },
    "browser-debug": {
      "command": "node",
      "args": ["C:/Users/Administrator/七云菜馆/browser-debug-mcp/server.js"],
      "disabled": false,
      "autoApprove": ["get_console_logs", "get_network_logs", "take_screenshot"]
    }
  }
}
```

### 步骤 2: 重启 Kiro 或重新连接 MCP

在 Kiro 中:
1. 打开命令面板(Ctrl+Shift+P)
2. 搜索 "MCP"
3. 选择 "Reconnect MCP Servers" 或重启 Kiro

### 步骤 3: 测试功能

在 Kiro 中对我说:

```
启动浏览器调试 http://localhost:8090
```

我会自动:
1. 启动 Edge 浏览器(您常用的浏览器!)
2. 访问您的管理后台
3. 开始监听控制台日志和网络请求

然后您可以说:

```
查看控制台有什么错误
```

我会直接返回所有错误信息,无需您手动复制粘贴!

## 🔧 故障排查

### 问题: MCP 服务器未显示

**解决方案**:
1. 检查 mcp.json 路径是否正确
2. 确保 Node.js 版本 >= 18
3. 在 Kiro 中查看 MCP 日志面板

### 问题: 浏览器启动失败

**解决方案**:
```bash
cd browser-debug-mcp
npx playwright install chromium --force
```

### 问题: 无法捕获日志

**解决方案**:
- 确保先调用 `start_browser_debug`
- 检查页面是否真的有控制台输出
- 尝试有头模式查看: "启动浏览器调试 http://localhost:8090 有头模式"
