# 快速配置 MCP 浏览器调试

## 方法一: 手动配置(推荐)

1. 在 Kiro 中按 `Ctrl+Shift+P` 打开命令面板
2. 输入 "Open User Settings (JSON)" 或 "打开用户设置"
3. 找到 MCP 配置文件,或直接打开: `C:/Users/Administrator/.kiro/settings/mcp.json`
4. 将内容替换为:

```json
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"],
      "env": {},
      "disabled": true,
      "autoApprove": []
    },
    "browser-debug": {
      "command": "node",
      "args": ["C:/Users/Administrator/七云菜馆/browser-debug-mcp/server.js"],
      "disabled": false,
      "autoApprove": ["get_console_logs", "get_network_logs", "take_screenshot"]
    }
  }
}
```

5. 保存文件
6. 在 Kiro 中按 `Ctrl+Shift+P`,输入 "MCP",选择 "Reconnect MCP Servers"

## 方法二: 使用 PowerShell 脚本

运行以下命令:

```powershell
# 备份原配置
Copy-Item "C:/Users/Administrator/.kiro/settings/mcp.json" "C:/Users/Administrator/.kiro/settings/mcp.json.backup"

# 写入新配置
@"
{
  "mcpServers": {
    "fetch": {
      "command": "uvx",
      "args": ["mcp-server-fetch"],
      "env": {},
      "disabled": true,
      "autoApprove": []
    },
    "browser-debug": {
      "command": "node",
      "args": ["C:/Users/Administrator/七云菜馆/browser-debug-mcp/server.js"],
      "disabled": false,
      "autoApprove": ["get_console_logs", "get_network_logs", "take_screenshot"]
    }
  }
}
"@ | Out-File -FilePath "C:/Users/Administrator/.kiro/settings/mcp.json" -Encoding UTF8
```

## 验证配置

配置完成后,在 Kiro 中:

1. 打开 MCP 面板(侧边栏)
2. 查看是否有 "browser-debug" 服务器
3. 状态应该是 "Connected" 或 "已连接"

## 测试功能

对我说:

```
启动浏览器调试 http://localhost:8090
```

如果 Edge 浏览器自动打开,说明配置成功! 🎉

## 故障排查

**问题: MCP 服务器未显示**
- 检查路径是否正确: `C:/Users/Administrator/七云菜馆/browser-debug-mcp/server.js`
- 确保 Node.js 已安装: `node --version`
- 查看 Kiro 的 MCP 日志面板

**问题: 服务器显示错误**
- 检查依赖是否安装: `cd browser-debug-mcp && npm list`
- 重新安装依赖: `npm install`

**问题: 浏览器启动失败**
- 确保 Edge 已安装
- 或使用 Chrome: 对我说 "用 Chrome 启动浏览器调试"
