# 云函数测试指南

## 🔴 当前问题

你的云函数上传成功但运行失败：
```
运行状态：失败
运行结果：（空）
运行日志：（空）
```

这是因为**云函数运行时没有提供测试参数**。

## ✅ 正确的测试步骤

### 方法 1：使用 HBuilderX 测试（推荐）

#### 步骤 1：重新上传云函数

1. 我已经更新了云函数代码，添加了详细的日志
2. 右键点击 `ai-chat` 云函数目录
3. 选择 **"上传部署"** → **"上传并运行"**
4. 等待上传完成

#### 步骤 2：使用测试参数运行

1. 上传完成后，右键点击 `ai-chat` 云函数
2. 选择 **"运行-云端云函数"**（注意是云端，不是本地）
3. 在弹出的测试窗口中，输入以下参数：

```json
{
  "message": "你好",
  "history": []
}
```

4. 点击 **"运行"** 按钮
5. 查看返回结果

#### 预期结果

**成功的返回：**
```json
{
  "code": 200,
  "success": true,
  "message": "你好！我是七云菜馆的AI点餐助手...",
  "usage": {
    "input_tokens": 50,
    "output_tokens": 30
  }
}
```

**如果失败：**
- 查看控制台的详细日志
- 日志会显示具体在哪一步失败了

---

### 方法 2：在 uniCloud 控制台测试

#### 步骤 1：打开控制台

1. 访问 [uniCloud 控制台](https://unicloud.dcloud.net.cn/)
2. 登录你的账号
3. 选择你的服务空间（demo）

#### 步骤 2：找到云函数

1. 点击左侧 **"云函数/云对象"**
2. 找到 `ai-chat` 云函数
3. 点击进入详情页

#### 步骤 3：在线测试

1. 点击 **"测试"** 标签
2. 在测试参数框中输入：

```json
{
  "message": "你好",
  "history": []
}
```

3. 点击 **"运行"** 按钮
4. 查看返回结果和日志

#### 步骤 4：查看日志

1. 点击 **"日志"** 标签
2. 查看最近的运行日志
3. 日志会显示详细的执行过程：
   - 云函数开始执行
   - 接收的参数
   - API 调用过程
   - 返回结果
   - 错误信息（如果有）

---

### 方法 3：在小程序中测试

如果云函数测试通过，就可以在小程序中测试了。

#### 步骤 1：重启小程序

1. 在微信开发者工具中清除缓存
2. 在 HBuilderX 中停止运行
3. 重新运行小程序

#### 步骤 2：测试 AI 助手

1. 点击右下角 🤖 按钮
2. 输入 "你好"
3. 查看是否有回复

#### 步骤 3：查看日志

在微信开发者工具控制台中，你应该能看到：

```
[AI] 开始调用，消息: 你好
云函数开始执行，接收参数: {message: "你好", history: []}
开始构建请求...
开始调用通义千问 API...
API 响应状态: 200
AI 回复成功: ...
[AI] 调用成功，完整响应: {...}
```

## 🔍 常见错误及解决方案

### 错误 1：运行失败，无日志

**原因：** 没有提供测试参数

**解决：** 使用上面的方法 1 或方法 2，提供正确的测试参数

---

### 错误 2：API Key 无效

**日志显示：**
```
API 响应状态: 401
错误: Invalid API Key
```

**解决：**
1. 检查 `index.js` 中的 API_KEY
2. 确认格式：`sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
3. 登录阿里云控制台验证 Key 是否有效
4. 重新上传云函数

---

### 错误 3：网络超时

**日志显示：**
```
云函数执行失败，错误详情: timeout
```

**解决：**
1. 检查云函数的网络配置
2. 增加超时时间（已设置为 30 秒）
3. 检查阿里云 API 是否可访问

---

### 错误 4：免费额度用完

**日志显示：**
```
API 响应状态: 429
错误: Rate limit exceeded
```

**解决：**
1. 登录阿里云控制台查看用量
2. 等待下月额度刷新
3. 或购买付费套餐

## 💡 调试技巧

### 技巧 1：查看完整日志

在 uniCloud 控制台的日志页面：
- 可以看到每次调用的完整日志
- 包括输入参数、执行过程、返回结果
- 可以筛选时间范围和日志级别

### 技巧 2：使用 console.log

我已经在云函数中添加了详细的 console.log：
- 每个关键步骤都有日志输出
- 可以清楚地看到执行到哪一步
- 可以看到具体的参数和返回值

### 技巧 3：分步测试

1. 先测试云函数是否能正常运行
2. 再测试 API 调用是否成功
3. 最后测试小程序集成
