### 3. 常见问题排查

#### 问题 1: 参数解析失败

**症状:** 扫码后没有显示弹窗

**排查步骤:**
1. 检查 URL 参数是否正确
2. 查看控制台是否有错误日志
3. 验证 `getTableInfo()` 返回值

**解决方案:**
```javascript
// 在 onLoad 中添加调试日志
onLoad(options) {
  console.log('启动参数:', options)
  const tableInfo = getTableInfo(options)
  console.log('解析结果:', tableInfo)
}
```

#### 问题 2: 本地存储失败

**症状:** 数据保存后读取不到

**排查步骤:**
1. 检查是否有存储权限
2. 查看存储空间是否已满
3. 验证数据格式是否正确

**解决方案:**
```javascript
// 检查存储信息
import { getStorageInfo } from '@/utils/localStorage.js'

const info = getStorageInfo()
console.log('存储信息:', info)
```

#### 问题 3: 状态不同步

**症状:** 状态更新后页面没有响应

**排查步骤:**
1. 检查是否正确初始化状态管理
2. 验证状态监听器是否正确添加
3. 确认状态更新是否触发

**解决方案:**
```javascript
// 在 App.vue 中初始化
import { initState } from '@/utils/stateManager.js'

onLaunch() {
  initState()
  console.log('状态管理已初始化')
}
```

## 性能优化建议

### 1. 减少不必要的存储操作

```javascript
// 不好的做法
for (let i = 0; i < 100; i++) {
  saveToLocalStorage(`key${i}`, value)
}

// 好的做法
const data = {}
for (let i = 0; i < 100; i++) {
  data[`key${i}`] = value
}
batchSave(data)
```

### 2. 使用状态缓存

```javascript
// 不好的做法
methods: {
  getTable() {
    return getTableState() // 每次都读取
  }
}

// 好的做法
data() {
  return {
    tableState: null
  }
},
onLoad() {
  this.tableState = getTableState() // 缓存状态
}
```

### 3. 避免频繁的环境检测

```javascript
// 不好的做法
methods: {
  doSomething() {
    const env = detectEnvironment() // 每次都检测
    if (env === 'mp-weixin') {
      // ...
    }
  }
}

// 好的做法
data() {
  return {
    env: detectEnvironment() // 只检测一次
  }
}
```
