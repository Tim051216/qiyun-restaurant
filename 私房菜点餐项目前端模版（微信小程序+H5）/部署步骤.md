## 📋 部署步骤（按顺序执行）

### 步骤 1：关联云服务空间

1. 在 HBuilderX 中，**右键点击** `uniCloud-aliyun` 目录
2. 选择 **"关联云服务空间或项目"**
3. 如果已有云服务空间，选择它；如果没有，创建新的

### 步骤 2：上传数据库 Schema

1. **右键点击** `uniCloud-aliyun/database/zhuohao.schema.json`
2. 选择 **"上传 DB Schema"**
3. 等待上传完成（控制台会显示成功信息）

### 步骤 3：上传云对象

1. **右键点击** `uniCloud-aliyun/cloudfunctions/zhuohao` 目录
2. 选择 **"上传部署"**
3. 选择 **"上传并运行"**
4. 等待部署完成（大约需要 10-30 秒）

### 步骤 4：配置微信凭证

**重要：这一步必须在云端配置！**

#### 方法 A：在 uniCloud Web 控制台配置（推荐）

1. 打开浏览器，访问：https://unicloud.dcloud.net.cn/
2. 登录并选择你的云服务空间
3. 点击左侧 **"云函数/云对象"**
4. 点击顶部 **"公共模块或扩展库"**
5. 找到或新建 **"uni-open-bridge"**
6. 添加配置：
```json
{
  "mp-weixin": {
    "appid": "wxc63d199886077877",
    "appsecret": "e51393d39a5e8515bc97542eca91f74b"
  }
}
```
7. 保存

#### 方法 B：使用环境变量

1. 在 uniCloud 控制台，点击 **"云函数/云对象"** → **"zhuohao"**
2. 点击 **"云函数配置"** 或 **"环境变量"**
3. 添加：
   - `WX_APPID` = `wxc63d199886077877`
   - `WX_APPSECRET` = `e51393d39a5e8515bc97542eca91f74b`
4. 保存

### 步骤 5：创建数据库索引

1. 在 uniCloud 控制台，进入 **"云数据库"**
2. 选择 `zhuohao` 表
3. 点击 **"索引管理"** → **"新建索引"**
4. 配置：
   - 字段名：`table_number`
   - 索引类型：**唯一索引**
5. 保存

### 步骤 6：运行小程序

1. 在 HBuilderX 中，点击顶部 **"运行"** 菜单
2. 选择 **"运行到小程序模拟器"** → **"微信开发者工具"**
3. 等待编译完成
4. 小程序会自动在微信开发者工具中打开

### 步骤 7：访问管理后台

在小程序中：
1. 点击底部 **"我的"** 标签
2. 滚动到底部
3. 点击 **"桌号管理"**
4. 进入管理后台

### 步骤 8：添加测试桌号

在管理后台：
1. 点击 **"添加桌号"** 按钮
2. 输入桌号（如：测试桌1）
3. 点击 **"确定"**
4. 等待生成完成

## ✅ 验证部署成功

1. 在 HBuilderX 中，**右键点击** `zhuohao` 云对象

## 🚨 常见问题

### Q1: 上传云对象失败？
**原因**：可能没有关联云服务空间
**解决**：右键 `uniCloud-aliyun` → 关联云服务空间

### Q2: 管理后台显示"没有更多数据"？
**原因**：这是正常的，因为还没有生成任何桌号
**解决**：点击"添加桌号"创建第一个桌号

### Q3: 生成小程序码失败？
**原因**：微信凭证未配置或配置错误
**解决**：
1. 检查 uniCloud 控制台的微信配置
2. 确认 AppID 和 AppSecret 正确
3. 查看云函数日志

### Q4: 小程序无法运行？
**原因**：可能是编译错误或配置问题
**解决**：
1. 检查 HBuilderX 控制台的错误信息
2. 确认已安装微信开发者工具
3. 检查 manifest.json 中的 AppID

### Q5: 找不到"桌号管理"入口？
**原因**：代码可能没有保存或编译
**解决**：
1. 保存所有文件（Ctrl+S）
2. 重新编译运行
3. 检查 pages/my/my.vue 是否已修改
