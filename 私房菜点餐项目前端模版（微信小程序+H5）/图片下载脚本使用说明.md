# 菜品图片批量下载脚本使用说明

## 📦 脚本文件

提供了两个下载脚本：

### 1. download_images_simple.py（推荐）
- ✅ 无需 API Key
- ✅ 直接使用 Unsplash 免费图片
- ✅ 简单易用
- ⚠️ 图片随机性较大，可能需要手动筛选

### 2. download_dish_images.py（高级）
- 需要 Pixabay API Key（免费）
- 搜索结果更精准
- 可以选择最佳图片
- 需要注册账号

## 🚀 快速开始（推荐方式）

### 方法1：使用简化脚本（无需注册）

1. **安装 Python**
   - 确保已安装 Python 3.6+
   - 检查：打开命令行输入 `python --version`

2. **安装依赖**
   ```bash
   pip install requests
   ```

3. **运行脚本**
   ```bash
   cd "私房菜点餐项目前端模版（微信小程序+H5）"
   python download_images_simple.py
   ```

4. **等待下载完成**
   - 脚本会自动下载所有 76 道菜品图片
   - 图片保存在 `static/menu/menulist/` 目录
   - 下载时间约 5-10 分钟

### 方法2：使用 Pixabay API（更精准）

1. **获取 API Key**
   - 访问 https://pixabay.com/
   - 注册/登录账号
   - 访问 https://pixabay.com/api/docs/
   - 复制你的 API Key

2. **配置脚本**
   - 打开 `download_dish_images.py`
   - 找到第 13 行：`PIXABAY_API_KEY = "YOUR_API_KEY_HERE"`
   - 替换为你的 API Key

3. **安装依赖**
   ```bash
   pip install requests
   ```

4. **运行脚本**
   ```bash
   python download_dish_images.py
   ```

### 2. 压缩图片（重要！）

下载的图片可能较大，需要压缩：

**在线压缩（推荐）：**
- TinyPNG: https://tinypng.com/
- Squoosh: https://squoosh.app/

**批量压缩工具：**
- Windows: [Caesium](https://saerasoft.com/caesium/)
- Mac: [ImageOptim](https://imageoptim.com/)
- 命令行: 
  ```bash
  # 安装 ImageMagick
  pip install pillow
  
  # 批量压缩
  python compress_images.py
  ```

### 3. 手动替换不合适的图片

如果某些图片不合适，可以：
1. 访问 https://pixabay.com/ 或 https://unsplash.com/
2. 搜索菜品名称
3. 下载更合适的图片
4. 重命名并替换

## 📦 图片压缩脚本

创建 `compress_images.py`：

```python
from PIL import Image
import os

def compress_images(input_dir, quality=85, max_size=800):
    """压缩图片"""
    for filename in os.listdir(input_dir):
        if filename.lower().endswith(('.jpg', '.jpeg', '.png')):
            filepath = os.path.join(input_dir, filename)
            
            try:
                img = Image.open(filepath)
                
                # 调整尺寸
                if img.width > max_size or img.height > max_size:
                    img.thumbnail((max_size, max_size), Image.Resampling.LANCZOS)
                
                # 转换为 RGB（如果是 PNG）
                if img.mode in ('RGBA', 'LA', 'P'):
                    background = Image.new('RGB', img.size, (255, 255, 255))
                    if img.mode == 'P':
                        img = img.convert('RGBA')
                    background.paste(img, mask=img.split()[-1] if img.mode == 'RGBA' else None)
                    img = background
                
                # 保存压缩后的图片
                img.save(filepath, 'JPEG', quality=quality, optimize=True)
                print(f"✅ 压缩完成: {filename}")
                
            except Exception as e:
                print(f"❌ 压缩失败 {filename}: {e}")

if __name__ == "__main__":
    compress_images("./static/menu/menulist")
    print("\n✨ 所有图片压缩完成！")
```

运行压缩：
```bash
pip install pillow
python compress_images.py
```

## 🎯 最佳实践

1. **先下载少量测试**
   - 修改脚本，只下载前 5-10 道菜
   - 检查图片质量
   - 满意后再下载全部

2. **保留原图备份**
   - 压缩前备份原图
   - 以防需要重新处理

3. **统一图片风格**
   - 选择相似风格的图片
   - 保持色调一致
   - 建议使用俯拍或 45 度角

4. **定期更新**
   - 根据季节更换菜品图片
   - 使用真实菜品照片更佳
