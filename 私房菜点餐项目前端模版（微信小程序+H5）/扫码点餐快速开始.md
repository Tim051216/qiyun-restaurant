# 扫码点餐功能 - 快速开始

## 🚀 5分钟快速上手

本指南帮助你快速了解和使用扫码点餐功能。

## 📋 前置条件检查

在开始之前，确保你已经：
- ✅ 安装了 HBuilderX
- ✅ 安装了微信开发者工具
- ✅ 有微信小程序账号（已认证）
- ✅ 获取了小程序 AppID 和 AppSecret

## 🎯 功能概述

扫码点餐功能让顾客通过扫描桌上的二维码：
1. 自动识别桌号
2. 选择就餐人数
3. 开始点餐流程

**支持平台：** 微信小程序 + H5

## 🔧 快速配置（3步）

### 步骤1：配置 uniCloud

1. 在 HBuilderX 中右键点击项目
2. 选择"创建 uniCloud 云服务空间"
3. 关联云服务空间

### 步骤2：配置环境变量

在 uniCloud Web 控制台中添加：
```
WECHAT_APPID=你的小程序AppID
WECHAT_SECRET=你的小程序AppSecret
```

### 步骤3：创建数据库

在 uniCloud Web 控制台中创建集合：
- `tables` - 存储桌号信息
- `error_logs` - 存储错误日志
- `access_token_cache` - 缓存微信 token

## 🔍 代码示例

### 使用启动参数处理
```javascript
import { getTableInfo, saveTableInfo } from '@/utils/launchParams.js'

// 获取桌号信息
const tableInfo = getTableInfo(options)
if (tableInfo.tableNumber) {
  console.log('桌号:', tableInfo.tableNumber)
  console.log('人数:', tableInfo.dinerCount)
}

// 保存桌号信息
saveTableInfo('A01', 2)
```

### 使用错误处理
```javascript
import { showError, showSuccess, ErrorType } from '@/utils/errorHandler.js'

// 显示错误
showError(ErrorType.NETWORK_TIMEOUT, () => {
  // 重试回调
  console.log('用户点击重试')
})

// 显示成功
showSuccess('保存成功')
```

### 使用本地存储
```javascript
import { TableStorage } from '@/utils/localStorage.js'

// 保存桌号
TableStorage.save('A01', 2)

// 获取桌号
const tableInfo = TableStorage.get()
console.log(tableInfo.tableNumber) // A01
console.log(tableInfo.dinerCount)  // 2

// 清除桌号
TableStorage.clear()
```

## 🐛 常见问题

### Q: 扫码后没有反应？
**A:** 检查以下几点：
1. 二维码是否清晰
2. 网络连接是否正常
3. 小程序版本是否最新

### Q: 弹窗没有显示？
**A:** 可能原因：
1. 已经确认过桌号（本地存储有记录）
2. 参数解析失败（重新扫码）

### Q: 如何清除测试数据？
**A:** 两种方法：
1. 长按小程序图标 → 删除
2. 在设置中清除小程序数据
