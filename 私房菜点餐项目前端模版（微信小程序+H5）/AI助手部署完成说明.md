## 🚀 部署步骤

### 步骤 1：上传云函数

1. 打开 HBuilderX
2. 右键点击 `uniCloud-aliyun/cloudfunctions/ai-chat` 文件夹
3. 选择"上传部署"
4. 等待上传完成

### 步骤 2：运行小程序

1. 在 HBuilderX 中点击"运行" -> "运行到小程序模拟器"
2. 或者点击"运行" -> "运行到微信开发者工具"

### 步骤 3：测试 AI 助手

1. 在首页右下角找到紫色的 AI 助手按钮（带🤖表情）
2. 点击按钮打开聊天窗口
3. 输入问题测试，例如：
   - "推荐几道招牌菜"
   - "有什么辣的菜品？"
   - "营业时间是几点？"

## ⚙️ 自定义配置

### 修改 AI 角色设定

编辑云函数 `uniCloud-aliyun/cloudfunctions/ai-chat/index.js`：

```javascript
{
  role: 'system',
  content: '你是七云菜馆的智能点餐助手...' // 修改这里
}
```

### 修改快捷问题

编辑组件 `components/ai-assistant/ai-assistant.vue`：

```javascript
quickQuestions: [
  '推荐几道招牌菜',
  '有什么辣的菜品？',
  // 添加更多问题
]
```

### 修改悬浮按钮位置

在组件样式中修改：

```scss
.ai-float-btn {
  right: 30rpx;   // 距离右边
  bottom: 150rpx; // 距离底部
}
```

## 🔧 高级配置

### 切换 AI 模型

在云函数中修改：

```javascript
model: 'qwen-turbo',  // 可选：qwen-turbo, qwen-plus, qwen-max
```

### 调整回复长度

```javascript
parameters: {
  max_tokens: 500,  // 最大输出长度
  temperature: 0.7  // 创造性（0-1）
}
```

## 🐛 常见问题

### 1. 云函数上传失败
**解决方案**：
- 检查网络连接
- 确认已登录 uniCloud
- 重新上传

### 2. AI 无响应
**解决方案**：
- 检查云函数是否上传成功
- 查看云函数日志
- 确认 AccessKey 配置正确

### 3. 聊天窗口不显示
**解决方案**：
- 检查组件是否正确引入
- 查看控制台错误信息
- 确认页面路径正确

## 📝 注意事项

1. **AccessKey 安全**：
   - 已配置在云函数中，前端无法访问
   - 不要将云函数代码提交到公开仓库

2. **免费额度**：
   - 注意查看使用量
   - 避免恶意调用

3. **性能优化**：
   - 可以添加缓存机制
   - 限制单用户调用频率
