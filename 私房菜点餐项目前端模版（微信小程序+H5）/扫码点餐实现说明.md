# 扫码点餐功能实现说明

## 功能概述

实现了完整的扫码点餐流程，用户扫描餐桌二维码后可以直接进入点餐页面，选择菜品并下单。

## 已实现功能

### 1. 后端实现

#### 微信登录
- **接口**: `POST /wechat/login`
- **功能**: 通过微信 code 换取 openid，自动创建或获取会员信息
- **文件**: 
  - `WeChatController.java` - 微信登录控制器
  - `WeChatUtil.java` - 微信工具类
  - `MemberServiceImpl.java` - 会员服务实现

#### 配置更新
- 已在 `application.yml` 中配置微信小程序 AppID 和 AppSecret
- 已在 `WebMvcConfiguration.java` 中排除微信登录接口的JWT拦截

### 2. 小程序端实现

#### API封装
- `api/wechat.js` - 微信登录API
- `api/order.js` - 订单相关API

#### 扫码点餐页面
- **页面**: `pages/scan-order/scan-order.vue`
- **功能**:
  - 显示桌号信息
  - 按分类展示菜品列表
  - 购物车功能（添加/删除/清空）
  - 实时计算总价和数量
  - 提交订单

## 使用流程

### 1. 生成餐桌二维码

有两种方式生成餐桌二维码：

#### 方式一：普通二维码（推荐用于测试）
生成包含桌号参数的URL二维码：
```
https://你的小程序路径?tableNo=A01
```

#### 方式二：小程序码（推荐用于生产）
调用微信API生成小程序码，传入scene参数：
```javascript
// 后端调用示例
POST https://api.weixin.qq.com/wxa/getwxacodeunlimit?access_token=TOKEN
{
  "scene": "A01",  // 桌号
  "page": "pages/scan-order/scan-order",
  "width": 430
}
```

### 2. 用户扫码流程

1. **扫码**: 用户使用微信扫描餐桌二维码
2. **打开小程序**: 自动跳转到扫码点餐页面
3. **获取桌号**: 页面从URL参数或scene值获取桌号
4. **浏览菜品**: 查看菜单，按分类浏览
5. **添加菜品**: 点击"+"按钮添加到购物车
6. **查看购物车**: 点击底部购物车查看已选菜品
7. **提交订单**: 点击"去结算"提交订单

### 3. 登录流程

小程序首次使用时需要登录：

```javascript
// 在 App.vue 或首页 onLaunch 中调用
wx.login({
  success: (res) => {
    if (res.code) {
      // 调用后端登录接口
      wechatLogin(res.code).then(result => {
        // 保存token
        uni.setStorageSync('token', result.data.token)
        uni.setStorageSync('member', result.data.member)
      })
    }
  }
})
```

## 注意事项

1. **AppID配置**: 确保 `application.yml` 中的微信AppID和AppSecret正确
2. **域名配置**: 生产环境需要在微信小程序后台配置服务器域名白名单
3. **HTTPS**: 生产环境必须使用HTTPS协议
4. **二维码有效期**: 小程序码永久有效，普通二维码需要设置有效期
5. **并发处理**: 高峰期需要考虑订单并发创建的处理
