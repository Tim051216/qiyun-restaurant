# 编译错误修复说明

## 修复时间
2026-02-08

## 问题描述

用户报告了两个主要编译错误：

1. **登录页面错误**：点击"微信授权登录"按钮时报错 `Cannot read property 'code' of undefined`
2. **扫码点餐页面错误**：小程序启动时报错 `TypeError: Cannot read property 'call' of undefined`

## 问题分析

### 问题1：登录页面错误

**错误代码**：
```javascript
// ❌ 错误的写法
const [loginErr, loginRes] = await uni.login()
```

**错误原因**：
- `uni.login()` 不支持数组解构的方式
- uni-app 的 API 需要使用回调函数或 Promise 包装

**正确写法**：
```javascript
// ✅ 正确的写法
const loginRes = await new Promise((resolve, reject) => {
  uni.login({
    success: (res) => resolve(res),
    fail: (err) => reject(err)
  })
})
```

### 问题2：扫码点餐页面错误

**错误原因**：
- `scan-order.vue` 导入了 `getDishesGrouped` 函数
- 但 `api/dish.js` 导出的是 `getAllDishesGrouped` 函数
- 函数名不匹配导致编译错误

**修复方案**：
将 `api/dish.js` 中的导出函数名改为 `getDishesGrouped`

## 技术要点

### uni-app API 调用规范

uni-app 的异步 API 有两种调用方式：

#### 方式1：回调函数（传统方式）
```javascript
uni.login({
  success: (res) => {
    console.log(res.code)
  },
  fail: (err) => {
    console.error(err)
  }
})
```

#### 方式2：Promise 包装（推荐）
```javascript
const res = await new Promise((resolve, reject) => {
  uni.login({
    success: (res) => resolve(res),
    fail: (err) => reject(err)
  })
})
console.log(res.code)
```

#### ❌ 错误方式：数组解构
```javascript
// 这种方式不支持！
const [err, res] = await uni.login()  // ❌
```

### 模块导入导出规范

确保导入和导出的函数名一致：

```javascript
// api/dish.js
export const getDishesGrouped = () => { ... }

// pages/scan-order/scan-order.vue
import { getDishesGrouped } from '@/api/dish.js'  // ✅ 名称一致
```

## 注意事项

1. **uni.login() 调用**：
   - 必须使用 Promise 包装或回调函数
   - 不能使用数组解构
   - 不能使用 async/await 直接调用

2. **API 导入导出**：
   - 确保导入和导出的函数名一致
   - 使用 ES6 模块语法
   - 避免使用默认导出和命名导出混用

3. **错误处理**：
   - 使用 try-catch 捕获异常
   - 给用户友好的错误提示
   - 记录详细的错误日志
