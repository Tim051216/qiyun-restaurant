# 扫码点餐功能部署指南

## 部署概述

本指南将帮助你完成扫码点餐功能的完整部署，包括云端配置、数据库初始化、环境变量设置等。

## 前置条件

### 1. 开发工具
- HBuilderX（最新版本）
- 微信开发者工具
- 浏览器（用于 H5 测试）

### 2. 账号准备
- DCloud 账号（用于 uniCloud）
- 微信小程序账号（已认证）
- 微信公众平台账号（用于获取 AppID 和 AppSecret）

### 3. 权限要求
- 微信小程序已开通云开发权限
- 已获取小程序 AppID 和 AppSecret

## 部署步骤

### 第一步：创建 uniCloud 服务空间

1. 打开 HBuilderX
2. 右键点击项目根目录
3. 选择 `创建 uniCloud 云服务空间`
4. 选择阿里云或腾讯云
5. 填写服务空间名称（如：qiyun-restaurant）
6. 等待服务空间创建完成

### 第二步：关联云服务空间

1. 右键点击 `uniCloud-aliyun` 目录
2. 选择 `关联云服务空间`
3. 选择刚才创建的服务空间
4. 等待关联完成

### 第三步：配置环境变量

1. 登录 uniCloud Web 控制台
2. 选择你的服务空间
3. 进入 `云函数/云对象` -> `环境变量`
4. 添加以下环境变量：

```
WECHAT_APPID=你的微信小程序AppID
WECHAT_SECRET=你的微信小程序AppSecret
```

**获取 AppID 和 AppSecret：**
1. 登录微信公众平台（mp.weixin.qq.com）
2. 进入 `开发` -> `开发管理` -> `开发设置`
3. 复制 AppID
4. 生成并复制 AppSecret（注意保密）

### 第四步：创建云数据库集合

#### 4.1 创建 tables 集合

1. 在 uniCloud Web 控制台中
2. 进入 `云数据库` -> `数据库`
3. 点击 `新建集合`
4. 集合名称：`tables`
5. 点击 `确定`

#### 4.2 设置 tables 集合索引

1. 进入 `tables` 集合
2. 点击 `索引管理`
3. 添加索引：
   - 字段：`tableNumber`
   - 类型：`唯一索引`
   - 排序：`升序`

#### 4.3 创建 error_logs 集合

1. 点击 `新建集合`
2. 集合名称：`error_logs`
3. 点击 `确定`

#### 4.4 设置 error_logs 集合索引

1. 进入 `error_logs` 集合
2. 点击 `索引管理`
3. 添加索引：
   - 字段：`timestamp`
   - 类型：`普通索引`
   - 排序：`降序`

### 第五步：创建云对象

#### 5.1 创建 table-qrcode 云对象

1. 在 HBuilderX 中
2. 右键点击 `uniCloud-aliyun/cloudfunctions` 目录
3. 选择 `新建云对象`
4. 输入名称：`table-qrcode`
5. 点击 `确定`

#### 5.2 编写云对象代码

创建文件 `uniCloud-aliyun/cloudfunctions/table-qrcode/index.obj.js`：

```javascript
// 云对象教程: https://uniapp.dcloud.net.cn/uniCloud/cloud-obj
// jsdoc语法提示教程：https://ask.dcloud.net.cn/docs/#//ask.dcloud.net.cn/article/129

const https = require('https')

module.exports = {
	_before: function () {
		// 通用预处理器
	},
	
	/**
	 * 生成小程序码
	 * @param {string} tableNumber - 桌号
	 * @returns {object} 生成结果
	 */
	async generateQRCode(tableNumber) {
		// 参数验证
		if (!tableNumber || typeof tableNumber !== 'string') {
			return {
				success: false,
				errMsg: '桌号不能为空'
			}
		}
		
		// 桌号格式验证（字母数字组合，1-10位）
		if (!/^[A-Za-z0-9]{1,10}$/.test(tableNumber)) {
			return {
				success: false,
				errMsg: '桌号格式不正确，只能包含字母和数字，长度1-10位'
			}
		}
		
		try {
			// 1. 获取 access_token
			const accessToken = await this.getAccessToken()
			
			if (!accessToken) {
				return {
					success: false,
					errMsg: '获取 access_token 失败'
				}
			}
			
			// 2. 生成小程序码
			const qrcodeBuffer = await this.generateMiniProgramCode(accessToken, tableNumber)
			
			if (!qrcodeBuffer) {
				return {
					success: false,
					errMsg: '生成小程序码失败'
				}
			}
			
			// 3. 上传到云存储
			const fileID = await this.uploadToCloudStorage(qrcodeBuffer, tableNumber)
			
			if (!fileID) {
				return {
					success: false,
					errMsg: '上传云存储失败'
				}
			}
			
			// 4. 保存到数据库
			const dbResult = await this.saveToDatabase(tableNumber, fileID)
			
			if (!dbResult.success) {
				return dbResult
			}
			
			// 5. 返回成功结果
			return {
				success: true,
				data: {
					tableNumber: tableNumber,
					qrcodeUrl: fileID,
					createTime: Date.now()
				}
			}
		} catch (error) {
			console.error('[GenerateQRCode] 错误:', error)
			
			// 记录错误日志
			await this.logError({
				operation: 'generateQRCode',
				errorCode: 'GENERATE_FAILED',
				errorMessage: error.message,
				context: {
					tableNumber: tableNumber
				}
			})
			
			return {
				success: false,
				errMsg: '生成失败：' + error.message
			}
		}
	},
	
	/**
	 * 获取 access_token
	 * @returns {string} access_token
	 */
	async getAccessToken() {
		const db = uniCloud.database()
		const collection = db.collection('access_token_cache')
		
		try {
			// 1. 尝试从数据库缓存获取
			const cacheResult = await collection
				.where({
					key: 'wechat_access_token'
				})
				.get()
			
			if (cacheResult.data.length > 0) {
				const cache = cacheResult.data[0]
				const now = Date.now()
				
				// 检查是否过期（提前5分钟刷新）
				if (cache.expireTime > now + 5 * 60 * 1000) {
					console.log('[GetAccessToken] 使用缓存的 token')
					return cache.value
				}
			}
			
			// 2. 缓存不存在或已过期，重新获取
			console.log('[GetAccessToken] 重新获取 token')
			
			const appid = process.env.WECHAT_APPID
			const secret = process.env.WECHAT_SECRET
			
			if (!appid || !secret) {
				throw new Error('未配置 WECHAT_APPID 或 WECHAT_SECRET')
			}
			
			const url = `https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=${appid}&secret=${secret}`
			
			const response = await this.httpsGet(url)
			const data = JSON.parse(response)
			
			if (data.errcode) {
				throw new Error(`获取 access_token 失败: ${data.errmsg}`)
			}
			
			const accessToken = data.access_token
			const expiresIn = data.expires_in || 7200
			
			// 3. 保存到数据库缓存
			const expireTime = Date.now() + expiresIn * 1000
			
			if (cacheResult.data.length > 0) {
				// 更新现有记录
				await collection.doc(cacheResult.data[0]._id).update({
					value: accessToken,
					expireTime: expireTime,
					updateTime: Date.now()
				})
			} else {
				// 创建新记录
				await collection.add({
					key: 'wechat_access_token',
					value: accessToken,
					expireTime: expireTime,
					createTime: Date.now()
				})
			}
			
			return accessToken
		} catch (error) {
			console.error('[GetAccessToken] 错误:', error)
			throw error
		}
	},
	
	/**
	 * 生成小程序码
	 * @param {string} accessToken - access_token
	 * @param {string} tableNumber - 桌号
	 * @returns {Buffer} 图片 Buffer
	 */
	async generateMiniProgramCode(accessToken, tableNumber) {
		try {
			const url = `https://api.weixin.qq.com/wxa/getwxacodeunlimit?access_token=${accessToken}`
			
			const postData = JSON.stringify({
				scene: `table=${tableNumber}`,
				page: 'pages/index/index',
				check_path: false,
				env_version: 'release',
				width: 430
			})
			
			const buffer = await this.httpsPost(url, postData)
			
			// 检查是否返回错误
			try {
				const json = JSON.parse(buffer.toString())
				if (json.errcode) {
					throw new Error(`生成小程序码失败: ${json.errmsg}`)
				}
			} catch (e) {
				// 不是 JSON，说明是图片 Buffer，正常
			}
			
			return buffer
		} catch (error) {
			console.error('[GenerateMiniProgramCode] 错误:', error)
			throw error
		}
	},
	
	/**
	 * 上传到云存储
	 * @param {Buffer} buffer - 图片 Buffer
	 * @param {string} tableNumber - 桌号
	 * @returns {string} fileID
	 */
	async uploadToCloudStorage(buffer, tableNumber) {
		try {
			const fileName = `qrcodes/table_${tableNumber}_${Date.now()}.png`
			
			const result = await uniCloud.uploadFile({
				cloudPath: fileName,
				fileContent: buffer
			})
			
			if (!result.fileID) {
				throw new Error('上传失败，未返回 fileID')
			}
			
			console.log('[UploadToCloudStorage] 上传成功:', result.fileID)
			return result.fileID
		} catch (error) {
			console.error('[UploadToCloudStorage] 错误:', error)
			
			// 重试一次
			try {
				console.log('[UploadToCloudStorage] 重试上传')
				const fileName = `qrcodes/table_${tableNumber}_${Date.now()}_retry.png`
				
				const result = await uniCloud.uploadFile({
					cloudPath: fileName,
					fileContent: buffer
				})
				
				return result.fileID
			} catch (retryError) {
				console.error('[UploadToCloudStorage] 重试失败:', retryError)
				throw retryError
			}
		}
	},
	
	/**
	 * 保存到数据库
	 * @param {string} tableNumber - 桌号
	 * @param {string} qrcodeUrl - 小程序码 URL
	 * @returns {object} 保存结果
	 */
	async saveToDatabase(tableNumber, qrcodeUrl) {
		const db = uniCloud.database()
		const collection = db.collection('tables')
		
		try {
			// 检查桌号是否已存在
			const existResult = await collection
				.where({
					tableNumber: tableNumber
				})
				.get()
			
			if (existResult.data.length > 0) {
				// 更新现有记录
				const docId = existResult.data[0]._id
				
				await collection.doc(docId).update({
					qrcodeUrl: qrcodeUrl,
					updateTime: Date.now()
				})
				
				console.log('[SaveToDatabase] 更新成功:', tableNumber)
			} else {
				// 创建新记录
				await collection.add({
					tableNumber: tableNumber,
					qrcodeUrl: qrcodeUrl,
					status: 'active',
					createTime: Date.now(),
					updateTime: Date.now()
				})
				
				console.log('[SaveToDatabase] 创建成功:', tableNumber)
			}
			
			return {
				success: true
			}
		} catch (error) {
			console.error('[SaveToDatabase] 错误:', error)
			return {
				success: false,
				errMsg: '保存到数据库失败：' + error.message
			}
		}
	},
	
	/**
	 * 获取桌号信息
	 * @param {string} tableNumber - 桌号
	 * @returns {object} 桌号信息
	 */
	async getTableInfo(tableNumber) {
		const db = uniCloud.database()
		const collection = db.collection('tables')
		
		try {
			const result = await collection
				.where({
					tableNumber: tableNumber
				})
				.get()
			
			if (result.data.length === 0) {
				return {
					success: false,
					errMsg: '桌号不存在'
				}
			}
			
			return {
				success: true,
				data: result.data[0]
			}
		} catch (error) {
			console.error('[GetTableInfo] 错误:', error)
			return {
				success: false,
				errMsg: '查询失败：' + error.message
			}
		}
	},
	
	/**
	 * 获取桌号列表
	 * @returns {object} 桌号列表
	 */
	async getTableList() {
		const db = uniCloud.database()
		const collection = db.collection('tables')
		
		try {
			const result = await collection
				.orderBy('createTime', 'desc')
				.get()
			
			return {
				success: true,
				data: result.data
			}
		} catch (error) {
			console.error('[GetTableList] 错误:', error)
			return {
				success: false,
				errMsg: '查询失败：' + error.message
			}
		}
	},
	
	/**
	 * 记录错误日志
	 * @param {object} errorInfo - 错误信息
	 * @returns {object} 记录结果
	 */
	async logError(errorInfo) {
		const db = uniCloud.database()
		const collection = db.collection('error_logs')
		
		try {
			const result = await collection.add({
				...errorInfo,
				timestamp: Date.now()
			})
			
			return {
				success: true,
				logId: result.id
			}
		} catch (error) {
			console.error('[LogError] 记录错误日志失败:', error)
			return {
				success: false,
				errMsg: error.message
			}
		}
	},
	
	/**
	 * HTTPS GET 请求
	 * @param {string} url - 请求 URL
	 * @returns {Promise<string>} 响应内容
	 */
	httpsGet(url) {
		return new Promise((resolve, reject) => {
			https.get(url, (res) => {
				let data = ''
				
				res.on('data', (chunk) => {
					data += chunk
				})
				
				res.on('end', () => {
					resolve(data)
				})
			}).on('error', (error) => {
				reject(error)
			})
		})
	},
	
	/**
	 * HTTPS POST 请求
	 * @param {string} url - 请求 URL
	 * @param {string} postData - POST 数据
	 * @returns {Promise<Buffer>} 响应 Buffer
	 */
	httpsPost(url, postData) {
		return new Promise((resolve, reject) => {
			const urlObj = new URL(url)
			
			const options = {
				hostname: urlObj.hostname,
				path: urlObj.pathname + urlObj.search,
				method: 'POST',
				headers: {
					'Content-Type': 'application/json',
					'Content-Length': Buffer.byteLength(postData)
				}
			}
			
			const req = https.request(options, (res) => {
				const chunks = []
				
				res.on('data', (chunk) => {
					chunks.push(chunk)
				})
				
				res.on('end', () => {
					const buffer = Buffer.concat(chunks)
					resolve(buffer)
				})
			})
			
			req.on('error', (error) => {
				reject(error)
			})
			
			req.write(postData)
			req.end()
		})
	}
}
```

## 常见问题

### 1. 云对象上传失败
**原因：** 未关联云服务空间或网络问题
**解决：** 检查云服务空间关联，重试上传

### 2. access_token 获取失败
**原因：** 环境变量未配置或 AppID/AppSecret 错误
**解决：** 检查环境变量配置，确认 AppID 和 AppSecret 正确

### 3. 小程序码生成失败
**原因：** access_token 无效或参数错误
**解决：** 检查 access_token 是否过期，检查参数格式

### 4. 云存储上传失败
**原因：** 云存储空间不足或网络问题
**解决：** 检查云存储空间，重试上传

### 5. 数据库操作失败
**原因：** 集合不存在或权限不足
**解决：** 检查数据库集合是否创建，检查权限设置

### 6. 小程序环境测试失败
**原因：** AppID 未配置或域名未添加白名单
**解决：** 检查 manifest.json 配置，添加域名白名单

### 7. H5 环境测试失败
**原因：** 跨域问题或 API 不兼容
**解决：** 检查跨域配置，使用兼容的 API
