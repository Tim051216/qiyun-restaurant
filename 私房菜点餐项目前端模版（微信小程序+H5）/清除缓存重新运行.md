# 清除缓存重新运行小程序

## 问题
代码已更新，但小程序还在使用旧代码（缓存问题）

## 解决步骤

### 方法 1：在 HBuilderX 中清除缓存（推荐）

1. **停止当前运行**
   - 点击 HBuilderX 顶部的 "停止" 按钮
   - 或按快捷键 `Ctrl + F2`

2. **清除编译缓存**
   - 在项目根目录找到 `unpackage` 文件夹
   - 右键点击 -> 删除
   - 或者手动删除整个 `unpackage` 文件夹

3. **重新运行**
   - 点击 "运行" -> "运行到小程序模拟器" -> "微信开发者工具"
   - 等待重新编译完成

### 方法 2：在微信开发者工具中清除缓存

1. **清除缓存**
   - 打开微信开发者工具
   - 点击顶部菜单 "工具" -> "清除缓存"
   - 选择 "清除全部缓存"

2. **重新编译**
   - 点击 "编译" 按钮
   - 或按快捷键 `Ctrl + B`

### 方法 3：完全重启（最彻底）

1. **关闭所有工具**
   - 关闭微信开发者工具
   - 关闭 HBuilderX

2. **删除缓存文件夹**
   ```
   删除：私房菜点餐项目前端模版（微信小程序+H5）/unpackage
   ```

3. **重新启动**
   - 打开 HBuilderX
   - 运行项目到微信开发者工具

## 验证是否成功

运行后，在微信开发者工具的控制台中查看日志：

✅ 正确的日志应该是：
```
[AI] 开始调用云函数，消息: 推荐几道招牌菜
```

❌ 如果还是旧日志：
```
[AI] 开始调用后端API，消息: 推荐几道招牌菜
```
说明缓存还没清除干净，重复上述步骤。

## 快速命令（Windows）

在项目根目录打开命令行，执行：
```cmd
rmdir /s /q "私房菜点餐项目前端模版（微信小程序+H5）\unpackage"
```

## 注意事项

1. 删除 `unpackage` 文件夹是安全的，它只包含编译后的临时文件
2. 每次修改代码后，如果发现没生效，都可以用这个方法
3. 清除缓存后首次编译会稍微慢一些，这是正常的
