# 菜品图片下载实用方案

## ⚠️ 自动下载脚本遇到的问题

运行自动下载脚本时遇到了 Unsplash API 服务不可用（503 错误）的问题。这是因为：
1. Unsplash Source API 已经不稳定
2. 免费 API 有访问限制
3. 需要注册获取 API Key

## 🎯 推荐解决方案

### 方案1：手动下载（最可靠）⭐⭐⭐⭐⭐

虽然需要一些时间，但这是最可靠的方法：

#### 步骤：
1. **访问 Pixabay**（推荐）
   - 网址：https://pixabay.com/
   - 优势：20,000+ 中餐图片，完全免费，无需注册

2. **搜索并下载**
   ```
   打开 https://pixabay.com/images/search/chinese%20food/
   
   按照下面的清单逐个搜索：
   - 麻婆豆腐 → 搜索 "mapo tofu"
   - 宫保鸡丁 → 搜索 "kung pao chicken"
   - 炒饭 → 搜索 "fried rice"
   ...
   ```

3. **下载设置**
   - 点击图片
   - 选择"免费下载"
   - 选择尺寸：1280×853 或更大
   - 下载到本地

4. **重命名并放置**
   - 重命名为对应的文件名（见下方清单）
   - 放到 `static/menu/menulist/` 目录

### 方案2：使用 Pixabay API（需注册）⭐⭐⭐⭐

1. **获取 API Key**
   - 访问 https://pixabay.com/api/docs/
   - 注册账号（免费）
   - 复制 API Key

2. **配置脚本**
   - 打开 `download_dish_images.py`
   - 将 API Key 填入第 13 行

3. **运行脚本**
   ```bash
   python download_dish_images.py
   ```

### 方案3：使用现有图片（快速测试）⭐⭐⭐

如果只是想快速测试项目，可以：
1. 使用占位图片服务
2. 或者先用几张通用美食图片

## 🔧 快速批量下载技巧

### 使用浏览器扩展

1. **Image Downloader（Chrome）**
   - 安装：https://chrome.google.com/webstore
   - 搜索 "Image Downloader"
   - 在 Pixabay 搜索页面使用

2. **Bulk Image Downloader**
   - 可以批量下载搜索结果
   - 自动过滤尺寸

### 使用命令行工具

如果你熟悉命令行：

```bash
# 安装 wget
# Windows: 下载 wget.exe
# Mac: brew install wget
# Linux: sudo apt-get install wget

# 批量下载（需要先获取图片URL列表）
wget -i image_urls.txt -P ./static/menu/menulist/
```

## 📦 图片处理流程

下载完成后：

1. **检查图片**
   - 确保图片清晰
   - 风格统一
   - 尺寸合适

2. **压缩图片**
   ```bash
   python compress_images.py
   ```
   或使用在线工具：https://tinypng.com/

3. **更新配置**
   - 检查 `common/menu.js` 中的图片路径
   - 确保文件名匹配

## 💡 实用建议

### 1. 分批下载
不要一次性下载所有图片，建议：
- 第一批：10-15 张主打菜品
- 第二批：20-30 张常见菜品
- 第三批：其余菜品

### 2. 保持风格统一
- 选择相似的拍摄角度（俯拍或 45 度）
- 保持色调一致
- 背景简洁

### 3. 优化图片
- 尺寸：800×800 像素
- 格式：JPG
- 大小：< 200KB

### 4. 备份原图
- 压缩前保留原图
- 以防需要重新处理
