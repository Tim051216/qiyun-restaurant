## 🔍 问题诊断

### 你遇到的错误

```
Error: [ai-chat]: FC invoke failed, resource exhausted.
网络连接失败，请稍后重试
```

### 错误原因

**核心问题：** 云函数 `ai-chat` 没有上传到 uniCloud 服务器

**为什么会这样？**
- uniCloud 是云端服务，需要先上传云函数才能使用
- 你的代码在本地，但云端还没有这个函数
- 就像你写了一个网站，但还没有部署到服务器上

---

## 💡 解决方案

### 核心思路

```
本地代码 → 上传到云端 → 小程序调用云端函数 → 返回结果
```

### 需要做的事

1. ✅ 创建/关联 uniCloud 服务空间（云端环境）
2. ✅ 上传云函数到服务空间（部署代码）
3. ✅ 重启小程序（使用新配置）
4. ✅ 测试功能（验证成功）

---

## 📝 详细步骤

### 步骤 1：打开 HBuilderX

确保你的项目已经在 HBuilderX 中打开。

**项目结构应该是这样的：**
```
私房菜点餐项目前端模版（微信小程序+H5）/
├── uniCloud-aliyun/
│   └── cloudfunctions/
│       └── ai-chat/
│           ├── index.js      ← 云函数代码
│           └── package.json  ← 云函数配置
├── api/
│   └── ai.js                 ← API 接口
├── components/
│   └── ai-assistant/
│       └── ai-assistant.vue  ← AI 组件
└── pages/
    └── index/
        └── index.vue         ← 首页
```

---

### 步骤 2：关联 uniCloud 服务空间

#### 2.1 找到 uniCloud 目录

在 HBuilderX 左侧项目树中，找到 `uniCloud-aliyun` 目录。

#### 2.2 右键点击

右键点击 `uniCloud-aliyun` 目录，会弹出菜单。

#### 2.3 选择关联服务空间

在菜单中选择：**"关联云服务空间"**

#### 2.4 创建或选择服务空间

**如果你已有服务空间：**
- 直接选择已有的服务空间
- 点击确定

**如果没有服务空间：**
- 点击 "创建新空间"
- 填写信息：
  - 服务空间名称：`qiyun-restaurant`（或任意名称）
  - 云服务商：选择 "阿里云"
  - 套餐：选择 "免费版"（足够使用）
- 点击创建
- 等待创建完成（约 30 秒）

#### 2.5 确认关联成功

关联成功后，`uniCloud-aliyun` 目录图标会变化，显示已关联状态。

---

### 步骤 3：上传云函数

#### 3.1 找到云函数目录

在项目树中找到：
```
uniCloud-aliyun/
└── cloudfunctions/
    └── ai-chat/  ← 这个目录
```

#### 3.2 右键点击 ai-chat 目录

右键点击 `ai-chat` 目录（不是 cloudfunctions，是 ai-chat）。

#### 3.3 选择上传部署

在弹出的菜单中选择：**"上传部署"**

然后选择：**"上传并运行"**

#### 3.4 等待上传完成

**上传过程：**
```
[1/4] 压缩云函数代码...
[2/4] 上传到云端...
[3/4] 安装依赖包...
[4/4] 启动云函数...
```

**预计时间：** 2-3 分钟（首次上传需要安装依赖）

**成功标志：**
```
✅ 云函数 ai-chat 上传成功
✅ 云函数已启动
```

#### 3.5 常见上传问题

**问题 1：上传失败 - 网络错误**
- 解决：检查网络连接，重试

**问题 2：上传失败 - 未登录**
- 解决：点击 HBuilderX 右上角登录 DCloud 账号

**问题 3：上传失败 - 服务空间未关联**
- 解决：重新执行步骤 2

---

### 步骤 4：验证云函数

#### 4.1 测试云函数

右键点击 `ai-chat` 云函数，选择：**"运行-本地云函数"**

#### 4.2 输入测试参数

在弹出的测试窗口中，输入：

```json
{
  "message": "你好",
  "history": []
}
```

#### 4.3 点击运行

点击 "运行" 按钮，查看返回结果。

**成功的返回示例：**
```json
{
  "code": 200,
  "success": true,
  "message": "你好！我是七云菜馆的AI点餐助手...",
  "usage": {
    "input_tokens": 50,
    "output_tokens": 30
  }
}
```

**如果返回错误：**
- 检查 API Key 是否正确
- 查看错误信息
- 参考 "常见问题" 章节

---

### 步骤 5：重启小程序

#### 5.1 清除微信开发者工具缓存

1. 打开微信开发者工具
2. 点击顶部菜单：**"清缓存"**
3. 选择：**"清除全部缓存"**
4. 关闭微信开发者工具

#### 5.2 停止 HBuilderX 运行

在 HBuilderX 中：
1. 点击顶部菜单：**"运行"**
2. 选择：**"停止运行"**

#### 5.3 重新运行

1. 点击：**"运行"** → **"运行到小程序模拟器"** → **"微信开发者工具"**
2. 等待编译完成
3. 微信开发者工具会自动打开

---

### 步骤 6：测试 AI 助手

#### 6.1 打开小程序

在微信开发者工具中，应该能看到小程序首页。

#### 6.2 点击 AI 助手按钮

在首页右下角，找到紫色的 🤖 按钮，点击它。

#### 6.3 测试对话

**方式 1：使用快捷问题**
- 点击任意快捷问题（如 "推荐几道招牌菜"）
- 等待 AI 回复

**方式 2：手动输入**
- 在输入框输入 "你好"
- 点击 "发送" 按钮
- 等待 AI 回复

#### 6.4 验证成功

**成功标志：**
- ✅ AI 助手窗口正常打开
- ✅ 快捷问题可以点击
- ✅ 发送消息后有回复
- ✅ 对话历史正常显示
- ✅ 控制台无错误信息

## ❓ 常见问题

### Q1：云函数上传失败

**错误：** `上传失败：网络错误`

**原因：**
- 网络连接问题
- DCloud 账号未登录
- 服务空间未关联

**解决方案：**
1. 检查网络连接
2. 登录 DCloud 账号（HBuilderX 右上角）
3. 重新关联服务空间
4. 重试上传

---

### Q2：云函数测试失败

**错误：** `Invalid API Key`

**原因：** 通义千问 API Key 配置错误

**解决方案：**
1. 打开 `uniCloud-aliyun/cloudfunctions/ai-chat/index.js`
2. 检查第 6 行：
```javascript
const API_KEY = 'sk-7daca2a765c440c39ada2566908488eb';
```
3. 确认这是你的通义千问 API Key
4. 如果不对，替换为正确的 Key
5. 重新上传云函数

---

### Q3：小程序调用失败

**错误：** `uniCloud is not initialized`

**原因：** uniCloud 未初始化

**解决方案：**
1. 检查 `manifest.json` 中的 uniCloud 配置
2. 确认服务空间已关联
3. 重新编译小程序
4. 清除缓存后重试

---

### Q4：AI 回复很慢

**现象：** 等待很久才有回复

**原因：**
- 网络延迟
- 通义千问 API 响应慢
- 云函数冷启动

**解决方案：**
- 正常现象，首次调用会慢一些
- 后续调用会快很多
- 如果一直很慢，检查网络

---

### Q5：免费额度用完

**错误：** `resource exhausted`

**原因：** 通义千问免费额度用完（每月 100 万 tokens）

**解决方案：**
1. 登录阿里云控制台查看用量
2. 等待下月额度刷新
3. 或购买付费套餐（很便宜）

## 🔧 调试技巧

### 技巧 1：查看云函数日志

**步骤：**
1. 打开 [uniCloud 控制台](https://unicloud.dcloud.net.cn/)
2. 选择你的服务空间
3. 点击 "云函数/云对象"
4. 选择 `ai-chat` 云函数
5. 点击 "日志" 标签
6. 查看最近的调用记录

**日志内容：**
- 调用时间
- 输入参数
- 返回结果
- 错误信息

---

### 技巧 2：查看小程序控制台

**步骤：**
1. 在微信开发者工具中
2. 打开 "调试器" 面板
3. 查看 "Console" 标签
4. 查找错误信息

**关键日志：**
```
[AI] 开始调用，消息: 你好
[AI] 调用成功，完整响应: {...}
[AI] 结果数据: {...}
```

---

### 技巧 3：手动测试云函数

在微信开发者工具控制台中运行：

```javascript
// 测试云函数是否可用
uniCloud.callFunction({
  name: 'ai-chat',
  data: {
    message: '测试',
    history: []
  },
  success: (res) => {
    console.log('✅ 测试成功:', res)
  },
  fail: (err) => {
    console.error('❌ 测试失败:', err)
  }
})
```
