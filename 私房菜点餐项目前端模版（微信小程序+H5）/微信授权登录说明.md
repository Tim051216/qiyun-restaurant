## 功能概述

本项目实现了符合微信最新规范（2022年10月后）的授权登录流程：

**一步式登录**：用户在登录页面直接填写头像和昵称，点击"立即登录"完成注册。

## 登录流程

```
用户打开小程序
    ↓
App.vue 检查登录状态
    ↓
未登录 → 跳转到登录页面
    ↓
用户看到登录表单（头像 + 昵称）
    ↓
用户点击头像按钮 → 选择头像
    ↓
用户输入昵称（键盘上方显示微信昵称建议）
    ↓
用户点击"立即登录"按钮
    ↓
调用 wx.login() 获取 code
    ↓
调用后端 /wechat/login 接口（传递 code + 头像 + 昵称）
    ↓
后端获取 openid 并创建/更新会员
    ↓
后端生成 JWT token
    ↓
前端保存 token 和会员信息
    ↓
登录成功，跳转到首页
```

### 前端实现

#### 1. 登录页面 (`pages/login/login.vue`)

**核心特性**：
- 使用 `open-type="chooseAvatar"` 获取头像（新API）
- 使用 `type="nickname"` 输入框获取昵称（新API）
- 一步式登录，用户体验流畅
- 专业的渐变UI设计

**完整代码示例**：

```vue
<template>
  <view class="login-container">
    <view class="login-box">
      <!-- Logo -->
      <view class="logo-section">
        <image class="logo" src="/static/index/banner.jpg"></image>
        <view class="app-name">七云菜馆</view>
        <view class="app-slogan">美食与您相伴</view>
      </view>
      
      <!-- 登录表单 -->
      <view class="profile-step">
        <view class="step-title">欢迎使用七云菜馆</view>
        <view class="step-desc">请完善您的个人信息</view>
        
        <view class="profile-form">
          <!-- 头像选择 -->
          <view class="form-item">
            <view class="item-label">头像</view>
            <button 
              class="avatar-btn" 
              open-type="chooseAvatar" 
              @chooseavatar="onChooseAvatar"
            >
              <image 
                class="avatar-img" 
                :src="avatarUrl || '/static/my/avatarurl.jpg'"
              ></image>
              <view class="avatar-tip">
                {{ avatarUrl ? '重新选择' : '点击选择头像' }}
              </view>
            </button>
          </view>
          
          <!-- 昵称输入 -->
          <view class="form-item">
            <view class="item-label">昵称</view>
            <input 
              class="nickname-input" 
              type="nickname"
              :value="nickname"
              @input="onNicknameInput"
              @blur="onNicknameBlur"
              placeholder="请输入昵称"
            />
          </view>
        </view>
        
        <!-- 登录按钮 -->
        <button 
          class="primary-btn" 
          :disabled="!canSubmit"
          @click="handleLogin"
        >
          立即登录
        </button>
        
        <!-- 隐私协议 -->
        <view class="privacy-tips">
          <text>登录即表示同意</text>
          <text class="link">《用户协议》</text>
          <text>和</text>
          <text class="link">《隐私政策》</text>
        </view>
      </view>
    </view>
  </view>
</template>

<script>
import { wechatLogin } from '@/api/wechat.js'
import { setToken, setMember } from '@/utils/auth.js'

export default {
  data() {
    return {
      avatarUrl: '',
      nickname: ''
    }
  },
  computed: {
    canSubmit() {
      return this.avatarUrl && this.nickname && this.nickname.trim().length > 0
    }
  },
  methods: {
    // 选择头像
    onChooseAvatar(e) {
      const { avatarUrl } = e.detail
      this.avatarUrl = avatarUrl
    },
    
    // 输入昵称（实时更新）
    onNicknameInput(e) {
      this.nickname = e.detail.value
    },
    
    // 昵称失焦（最终确认）
    onNicknameBlur(e) {
      this.nickname = e.detail.value.trim()
    },
    
    // 登录
    async handleLogin() {
      if (!this.canSubmit) {
        uni.showToast({
          title: '请完善头像和昵称',
          icon: 'none'
        })
        return
      }
      
      uni.showLoading({ title: '登录中...' })
      
      try {
        // 1. 获取 code
        const loginRes = await new Promise((resolve, reject) => {
          uni.login({
            success: (res) => resolve(res),
            fail: (err) => reject(err)
          })
        })
        
        if (!loginRes.code) {
          throw new Error('获取登录凭证失败')
        }
        
        // 2. 调用后端登录接口
        const userInfo = {
          nickName: this.nickname,
          avatarUrl: this.avatarUrl
        }
        
        const res = await wechatLogin(loginRes.code, userInfo)
        
        if (res.code === 1 || res.code === 200) {
          // 3. 保存 token 和会员信息
          setToken(res.data.token)
          setMember(res.data.member)
          
          uni.hideLoading()
          uni.showToast({
            title: '登录成功',
            icon: 'success'
          })
          
          // 4. 跳转到首页
          setTimeout(() => {
            uni.switchTab({
              url: '/pages/index/index'
            })
          }, 1500)
        } else {
          throw new Error(res.msg || '登录失败')
        }
      } catch (error) {
        console.error('登录失败:', error)
        uni.hideLoading()
        uni.showToast({
          title: error.message || '登录失败，请重试',
          icon: 'none'
        })
      }
    }
  }
}
</script>
```

### 后端实现

#### 1. 微信登录接口 (`WeChatController.java`)

```java
@PostMapping("/login")
public Result<Map<String, Object>> login(@RequestBody Map<String, Object> params) {
    String code = (String) params.get("code");
    Map<String, Object> userInfo = (Map<String, Object>) params.get("userInfo");
    
    // 1. 调用微信接口获取 openid
    String openid = WeChatUtil.getOpenid(code);
    
    // 2. 根据 openid 查询或创建会员
    Member member = memberService.getOrCreateByOpenid(openid);
    
    // 3. 更新会员信息（头像和昵称）
    if (userInfo != null) {
        String nickName = (String) userInfo.get("nickName");
        String avatarUrl = (String) userInfo.get("avatarUrl");
        
        member.setNickname(nickName);
        member.setAvatar(avatarUrl);
        memberService.updateById(member);
    }
    
    // 4. 生成 JWT token
    String token = JwtUtil.createJWT(member.getId().toString());
    
    // 5. 返回结果
    Map<String, Object> result = new HashMap<>();
    result.put("token", token);
    result.put("member", member);
    
    return Result.success(result);
}
```
