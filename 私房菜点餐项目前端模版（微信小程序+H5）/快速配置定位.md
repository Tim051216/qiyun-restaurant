# 快速配置定位功能

## 只需3步，5分钟完成配置！

### 第1步：获取餐厅坐标（2分钟）

1. 打开网址：https://lbs.qq.com/getPoint/
2. 在搜索框输入你的餐厅地址
3. 点击搜索结果
4. 复制显示的经纬度（例如：39.9042, 116.4074）

### 第2步：修改配置文件（2分钟）

打开文件：`config/restaurant.js`

修改这几行：

```javascript
export default {
	name: '你的餐厅名称',           // 改这里
	address: '你的餐厅详细地址',    // 改这里
	phone: '你的电话号码',          // 改这里
	
	location: {
		latitude: 39.9042,          // 改成你的纬度
		longitude: 116.4074         // 改成你的经度
	}
}
```

### 第3步：测试（1分钟）

1. 保存文件
2. 重新编译小程序
3. 在首页顶部查看位置信息

## 完成！

现在你的小程序已经有定位功能了：

✅ 首页显示到店距离
✅ 点击可以查看地图
✅ 点击可以导航到店

## 示例

假设你的餐厅是"老北京炸酱面馆"，地址是"北京市朝阳区建国路88号"

配置文件应该这样写：

```javascript
export default {
	name: '老北京炸酱面馆',
	address: '北京市朝阳区建国路88号',
	phone: '010-88888888',
	
	location: {
		latitude: 39.9042,   // 从腾讯地图获取
		longitude: 116.4074  // 从腾讯地图获取
	}
}
```
