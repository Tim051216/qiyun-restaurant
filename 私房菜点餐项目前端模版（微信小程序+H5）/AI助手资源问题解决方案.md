# 🔴 AI 助手资源问题解决方案

## 问题诊断

**错误信息：** `FC invoke failed, resource exhausted`

**根本原因：** uniCloud 免费服务空间资源额度已耗尽
- 已使用：1001.07 GBs
- 免费额度：1000.00 GBs
- 超出：1.07 GBs

**为什么会超额？**
uniCloud 的计费单位是 GBs（GB-秒），计算公式：
```
GBs = 内存(GB) × 运行时间(秒) × 调用次数
```

例如：
- 云函数内存：512MB = 0.5GB
- 每次运行：2秒
- 调用 1000 次 = 0.5 × 2 × 1000 = 1000 GBs

**可能的原因：**
1. 云函数被频繁调用（测试、调试）
2. 其他云函数（如 `zhuohao`）也在消耗资源
3. 云函数运行时间较长
4. 内存配置较高

## 💡 解决方案（4 个选项）

### 方案 1：删除旧服务空间，创建新的免费空间 ⭐ 推荐

**优点：**
- 完全免费
- 立即可用
- 重新获得 1000 GBs 免费额度

**缺点：**
- 会丢失当前服务空间的所有数据
- 需要重新配置和上传云函数

**操作步骤：**

#### 1. 备份重要数据（如果有）
- 导出数据库数据（如果使用了云数据库）
- 保存云函数代码（已在本地，无需额外备份）

#### 2. 删除旧服务空间
1. 访问 https://unicloud.dcloud.net.cn/
2. 登录账号
3. 选择服务空间 "demo"
4. 点击右上角 "设置"
5. 滚动到底部，点击 "删除服务空间"
6. 确认删除

#### 3. 创建新的免费服务空间
1. 在 uniCloud 控制台首页
2. 点击 "创建服务空间"
3. 选择 "阿里云"
4. 选择 "免费版"
5. 输入服务空间名称（如 "demo-new" 或 "restaurant-ai"）
6. 点击 "创建"

#### 4. 在 HBuilderX 中关联新服务空间
1. 右键点击 `uniCloud-aliyun` 目录
2. 选择 "关联云服务空间"
3. 选择刚创建的新服务空间
4. 点击 "确定"

#### 5. 重新上传云函数
1. 右键点击 `uniCloud-aliyun/cloudfunctions/ai-chat`
2. 选择 "上传部署" → "上传并运行"
3. 等待上传完成

#### 6. 测试 AI 助手
1. 重启小程序
2. 点击 AI 助手按钮
3. 发送测试消息

**预计时间：** 10-15 分钟

### 方案 4：优化云函数，减少资源消耗 ⭐ 长期方案

即使选择方案 1，也建议实施此方案，避免再次超额。

#### 4.1 减少云函数内存配置

**当前配置：** 默认 512MB

**优化方案：** 降低到 256MB 或 128MB

**如何配置：**
1. 在 `ai-chat` 目录创建 `package.json`（如果没有）
2. 添加配置：
```json
{
  "cloudfunction-config": {
    "memorySize": 256,
    "timeout": 10
  }
}
```

**效果：**
- 内存从 512MB 降到 256MB
- 资源消耗减少 50%

#### 4.2 添加请求频率限制

在云函数中添加简单的频率限制：

```javascript
// 在 index.js 开头添加
const requestCache = {};
const RATE_LIMIT = 10; // 每分钟最多 10 次请求

exports.main = async (event, context) => {
  // 获取用户标识（可以用 openid 或其他）
  const userId = context.OPENID || 'anonymous';
  const now = Date.now();
  
  // 检查频率限制
  if (requestCache[userId]) {
    const { count, timestamp } = requestCache[userId];
    if (now - timestamp < 60000) { // 1 分钟内
      if (count >= RATE_LIMIT) {
        return {
          code: 429,
          success: false,
          message: '请求过于频繁，请稍后再试'
        };
      }
      requestCache[userId].count++;
    } else {
      requestCache[userId] = { count: 1, timestamp: now };
    }
  } else {
    requestCache[userId] = { count: 1, timestamp: now };
  }
  
  // 原有代码...
};
```

#### 4.3 删除或停用不必要的云函数

如果 `zhuohao` 云函数不再使用：

1. 在 uniCloud 控制台
2. 找到 `zhuohao` 云函数
3. 点击 "删除" 或 "停用"

#### 4.4 优化 AI 调用

**当前问题：** 每次调用都发送完整历史记录

**优化方案：** 限制历史记录数量

```javascript
// 在云函数中
const MAX_HISTORY = 5; // 最多保留 5 条历史记录

exports.main = async (event, context) => {
  let { message, history = [] } = event;
  
  // 限制历史记录数量
  if (history.length > MAX_HISTORY) {
    history = history.slice(-MAX_HISTORY);
  }
  
  // 原有代码...
};
```

## ❓ 常见问题

### Q1：删除服务空间会丢失什么？
A：会丢失云数据库、云存储、云函数配置等。但本地代码不会丢失。

### Q2：新服务空间需要重新配置吗？
A：只需要重新上传云函数，其他配置（API Key 等）已在代码中。

### Q3：为什么会超额这么多？
A：可能是测试时频繁调用，或其他云函数也在消耗资源。

### Q4：如何避免再次超额？
A：实施方案 4 的优化措施，降低内存配置，添加频率限制。

### Q5：按量计费实际要花多少钱？
A：对于小型项目，每月通常只需几元钱。但需要 200 元保证金。
