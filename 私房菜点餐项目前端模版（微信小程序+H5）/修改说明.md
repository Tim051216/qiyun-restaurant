# 桌号管理功能 - 修改说明

## 问题原因

管理页面和主页的桌号弹窗使用了 uView UI 组件（`<u-button>`, `<u-popup>`, `<u-number-box>` 等），但这些组件没有正确渲染，导致界面显示异常。

## 解决方案

将所有 uView 组件替换为原生 uni-app 组件，确保在所有环境下都能正常显示。

## 修改的文件

### 1. pages/admin/table-management.vue（桌号管理页面）

**替换的组件：**
- `<u-button>` → `<button>` 原生按钮
- `<u-input>` → `<input>` 原生输入框
- `<u-popup>` → 自定义模态框（使用 fixed 定位）
- `<u-loading>` → 简单的文本提示
- `<u-empty>` → 简单的文本提示

**新增功能：**
- 自定义模态框样式（.modal-mask, .modal-content）
- 完整的按钮样式（.btn, .btn-mini, .btn-page）
- 输入框样式（.input）
- 空状态提示

### 2. pages/index/index.vue（主页 - 桌号弹窗）

**替换的组件：**
- `<u-popup>` → 自定义模态框
- `<u-number-box>` → 自定义数字选择器（+ - 按钮）
- `<u-button>` → `<button>` 原生按钮

**新增方法：**
- `increaseDiner()` - 增加就餐人数
- `decreaseDiner()` - 减少就餐人数

**新增样式：**
- 模态框样式（.modal-mask, .modal-content）
- 数字选择器样式（.number-box, .number-btn, .number-value）
- 确认按钮样式（.confirm-btn）

### 3. uniCloud-aliyun/cloudfunctions/zhuohao/index.obj.js（云对象）

**修改内容：**
- 在 `getWeixinAPI()` 调用时直接传入微信凭证
- 添加了 `appid` 和 `secret` 参数

```javascript
const wxApi = uniCloud.getWeixinAPI({
    appid: 'wxc63d199886077877',
    secret: 'e51393d39a5e8515bc97542eca91f74b'
})
```

这样就不需要在 uniCloud 控制台单独配置微信凭证了。

## 其他页面

以下页面是原项目自带的，使用了 uView 组件，但应该已经正常工作：
- pages/menu/menu.vue（点餐页面）
- pages/order/order.vue（订单页面）
- pages/my/my.vue（我的页面）

如果这些页面也出现显示问题，可以按照同样的方法替换为原生组件。

## 部署步骤

1. **保存所有文件**（Ctrl+S）
2. **上传数据库 Schema**
   - 右键 `uniCloud-aliyun/database/zhuohao.schema.json`
   - 选择 "上传 DB Schema"
3. **上传云对象**
   - 右键 `uniCloud-aliyun/cloudfunctions/zhuohao`
   - 选择 "上传部署" → "上传并运行"
4. **运行小程序**
   - 点击 "运行" → "运行到小程序模拟器" → "微信开发者工具"
5. **测试功能**
   - 点击 "我的" → "桌号管理"
   - 点击 "添加桌号" 测试

## 预期效果

### 桌号管理页面
- 顶部显示"桌号管理"标题
- 右侧有"添加桌号"和"批量生成"两个按钮
- 中间显示"暂无桌号数据"（初始状态）
- 点击"添加桌号"弹出输入框
- 输入桌号后点击"确定"生成小程序码

### 主页桌号弹窗
- 扫码后自动弹出"欢迎光临"对话框
- 显示当前桌号
- 可以通过 + - 按钮选择就餐人数（1-20人）
- 点击"确认"保存信息并关闭弹窗

## 注意事项

1. 确保已关联云服务空间
2. 确保云对象已上传部署
3. 确保数据库 Schema 已上传
4. 微信凭证已直接写在代码中，无需额外配置
5. 第一次生成桌号可能需要等待几秒钟

## 常见问题

**Q: 点击"添加桌号"没有反应？**
A: 检查是否已上传云对象到云端

**Q: 生成失败提示"微信 API 调用失败"？**
A: 检查微信 AppID 和 AppSecret 是否正确

**Q: 界面样式不对？**
A: 确保已保存所有文件并重新编译运行

**Q: 扫码后没有弹窗？**
A: 检查小程序码是否正确生成，scene 参数是否包含桌号
