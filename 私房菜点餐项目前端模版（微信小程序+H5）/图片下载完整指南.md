# 菜品图片下载完整指南

## 问题说明

之前下载的图片存在以下问题：
1. 图片质量较差
2. 部分图片与菜品名称不匹配
3. 没有预览就直接下载

## 新的解决方案

我创建了一个**交互式搜索工具**，让你可以：
- ✅ 先预览图片再决定是否下载
- ✅ 从多个高质量图片网站搜索
- ✅ 手动选择最合适的图片
- ✅ 确保图片质量和匹配度

## 使用步骤

### 第一步：打开搜索页面

运行命令：
```bash
python preview_and_download.py
```

或者直接在浏览器中打开：
```
dish_image_search.html
```

### 第二步：搜索图片

页面会显示所有69道菜品，每道菜有3个搜索按钮：

1. **Unsplash** - 高质量专业摄影（推荐）
2. **Pexels** - 免费高清图片
3. **Pixabay** - 中文搜索支持

点击任意按钮会在新标签页打开对应的搜索结果。

### 第三步：复制图片URL

在图片网站找到满意的图片后：

1. **右键点击图片**
2. 选择 **"复制图片地址"** 或 **"Copy image address"**
3. 返回搜索页面
4. 粘贴到对应菜品的输入框
5. 点击 **"保存URL"** 按钮

### 第四步：生成下载脚本

完成所有（或部分）菜品后：

1. 查看右下角的进度显示
2. 点击 **"生成下载脚本"** 按钮
3. 会自动下载 `download_dish_images_final.py` 文件

### 第五步：执行下载

运行生成的脚本：
```bash
python download_dish_images_final.py
```

脚本会自动下载所有你选择的图片到 `static/menu/menulist/` 目录。

## 图片选择建议

### 川菜类（麻辣风）
- 要有明显的红油、辣椒
- 颜色鲜艳，有食欲感
- 最好是俯拍或45度角

### 家常小炒
- 食材清晰可见
- 色泽自然
- 避免过度修图

### 时蔬素菜
- 颜色鲜绿
- 食材新鲜
- 简洁干净

### 汤品主食
- 汤汁清澈或浓郁（根据菜品）
- 碗具简洁
- 有热气感更佳

### 烧烤类
- 要有烧烤痕迹
- 色泽金黄
- 最好有烟火气

### 龙虾类
- 龙虾要完整
- 颜色鲜艳
- 摆盘精致

### 饮品酒水
- 瓶身或杯子清晰
- 有冰块或水珠更佳
- 背景简洁

## 图片质量要求

- **尺寸**：至少 800×600 像素
- **格式**：JPG 或 PNG
- **大小**：每张 < 1MB（脚本会自动下载）
- **风格**：尽量统一，建议都选择俯拍或45度角
- **背景**：浅色背景更佳

## 常见问题

### Q: 如何判断图片URL是否正确？

A: 正确的图片URL应该：
- 以 `http://` 或 `https://` 开头
- 以 `.jpg`、`.jpeg` 或 `.png` 结尾
- 例如：`https://images.unsplash.com/photo-xxx.jpg`

### Q: 复制的不是图片地址怎么办？

A: 确保右键点击的是图片本身，不是图片周围的区域。如果还是不行，可以：
1. 点击图片打开大图
2. 在大图上右键复制地址

### Q: 某些网站无法复制图片地址？

A: 可以尝试：
1. 点击下载按钮，查看下载链接
2. 使用浏览器的"检查元素"功能查找图片URL
3. 或者换一个图片网站搜索

### Q: 下载失败怎么办？

A: 可能原因：
1. URL已过期 - 重新搜索并复制新的URL
2. 网络问题 - 检查网络连接
3. 图片网站限制 - 换一个图片网站

### Q: 可以只下载部分菜品吗？

A: 可以！你可以：
1. 只为需要的菜品保存URL
2. 生成脚本时只会下载你保存的那些
3. 其他菜品可以稍后再补充
