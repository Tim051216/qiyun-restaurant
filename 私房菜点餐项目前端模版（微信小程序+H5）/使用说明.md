## 📱 如何使用

### 一、部署云端

#### 1. 上传数据库 Schema
在 HBuilderX 中：
1. 右键点击 `uniCloud-aliyun/database/zhuohao.schema.json`
2. 选择 **"上传 DB Schema"**

#### 2. 配置微信凭证
打开浏览器访问：https://unicloud.dcloud.net.cn/
1. 登录并选择云服务空间
2. 点击 **"云函数/云对象"** → **"公共模块或扩展库"**
3. 找到或新建 **"uni-open-bridge"**
4. 添加配置：
```json
{
  "mp-weixin": {
    "appid": "wxc63d199886077877",
    "appsecret": "e51393d39a5e8515bc97542eca91f74b"
  }
}
```

#### 3. 上传云对象
在 HBuilderX 中：
1. 右键点击 `uniCloud-aliyun/cloudfunctions/zhuohao` 目录
2. 选择 **"上传部署"**
3. 等待部署完成

#### 4. 创建数据库索引
在 uniCloud 控制台：
1. 进入 **"云数据库"** → 选择 `zhuohao` 表
2. 点击 **"索引管理"** → **"新建索引"**
3. 字段：`table_number`，类型：**唯一索引**

### 二、运行小程序

#### 1. 运行到微信开发者工具
在 HBuilderX 中：
1. 点击 **"运行"** → **"运行到小程序模拟器"** → **"微信开发者工具"**
2. 小程序会自动打开

#### 2. 访问管理后台
在小程序中：
1. 点击底部 **"我的"** 标签
2. 滚动到底部，点击 **"桌号管理"**
3. 进入管理后台

### 三、管理桌号

#### 添加单个桌号
1. 在管理页面点击 **"添加桌号"** 按钮
2. 输入桌号（如：桌1、A01）
3. 点击 **"确定"**
4. 等待生成完成

#### 批量生成桌号
1. 点击 **"批量生成"** 按钮
2. 输入：
   - 前缀：桌
   - 起始号：1
   - 结束号：10
3. 点击 **"生成"**
4. 系统会自动生成：桌1、桌2、...、桌10

#### 查看和管理
- **预览**：点击小程序码图片可以预览
- **下载**：点击 **"下载"** 按钮保存到相册
- **删除**：点击 **"删除"** 按钮删除桌号

### 四、测试扫码功能

#### 方法 1：使用真机测试
1. 在管理后台下载小程序码
2. 使用微信扫描小程序码
3. 小程序会自动打开并显示桌号弹窗
4. 选择就餐人数并确认

#### 方法 2：模拟扫码参数
在微信开发者工具中：
1. 点击 **"编译"** 旁边的下拉箭头
2. 选择 **"添加编译模式"**
3. 启动参数填入：`scene=桌1`
4. 点击编译

## 📞 常见问题

### Q1: 管理后台显示"没有更多数据"？
**A**: 这是正常的，因为还没有生成任何桌号。点击"添加桌号"或"批量生成"创建桌号。

### Q2: 生成小程序码失败？
**A**: 
1. 检查微信凭证是否正确配置
2. 查看云函数日志
3. 确认网络连接正常

### Q3: 如何打印小程序码？
**A**: 
1. 在管理后台点击"下载"保存到相册
2. 从相册导出到电脑
3. 使用打印机打印
4. 放置在对应的餐桌上

### Q4: 扫码无法识别桌号？
**A**: 
1. 确认小程序已发布或在开发者列表中
2. 检查桌号长度是否超过32字符
3. 使用真机测试（模拟器不支持扫码）
