# HBuilderX 运行指南

## 为什么需要 HBuilderX？

这是一个 **uni-app 项目**，不是原生微信小程序项目。uni-app 项目需要编译后才能在微信开发者工具中运行。

### uni-app vs 原生小程序

| 特性 | uni-app | 原生小程序 |
|------|---------|-----------|
| 配置文件 | pages.json, manifest.json | app.json |
| 语法 | Vue | 微信小程序语法 |
| 运行方式 | 需要编译 | 直接运行 |
| 跨平台 | ✅ 支持多端 | ❌ 仅微信 |

## 安装 HBuilderX

1. **下载地址**：https://www.dcloud.io/hbuilderx.html
2. **选择版本**：下载"正式版"即可
3. **安装**：解压即用，无需安装

## 运行步骤

### 第一步：打开项目

1. 启动 HBuilderX
2. 点击"文件" → "打开目录"
3. 选择项目目录：`私房菜点餐项目前端模版（微信小程序+H5）`

### 第二步：配置微信开发者工具路径

1. 点击"工具" → "设置" → "运行配置"
2. 找到"微信开发者工具路径"
3. 设置为你的微信开发者工具安装路径，例如：
   ```
   C:\Program Files (x86)\Tencent\微信web开发者工具
   ```

### 第三步：运行到微信开发者工具

1. 在 HBuilderX 中，点击顶部菜单"运行" → "运行到小程序模拟器" → "微信开发者工具"
2. 或者使用快捷键：`Ctrl + R`，然后选择"微信开发者工具"
3. 首次运行会自动编译，需要等待几秒

### 第四步：查看效果

- HBuilderX 会自动打开微信开发者工具
- 编译后的代码在：`unpackage/dist/dev/mp-weixin`
- 可以在微信开发者工具中预览和调试

## 常见问题

### 1. 微信开发者工具未自动打开

**原因**：路径配置不正确或服务端口未开启

**解决**：
1. 检查微信开发者工具路径配置
2. 在微信开发者工具中，点击"设置" → "安全设置"
3. 开启"服务端口"选项

### 2. 编译失败

**原因**：依赖未安装

**解决**：
```bash
cd 私房菜点餐项目前端模版（微信小程序+H5）
npm install
```

### 3. 页面显示空白

**原因**：后端服务未启动

**解决**：
1. 运行启动脚本：`.\start-all.ps1`
2. 确认后端服务运行在 http://localhost:8080

### 4. 401 Unauthorized 错误

**原因**：微信登录接口需要真实的微信授权

**解决**：
- 开发环境可以先跳过登录，直接进入菜单页面
- 或者在 `utils/request.js` 中添加测试 token

## 方案2：不使用 HBuilderX

如果不想安装 HBuilderX，可以使用命令行编译：

### 安装 uni-app CLI

```bash
npm install -g @dcloudio/uvm
uvm use latest
```

### 编译项目

```bash
cd 私房菜点餐项目前端模版（微信小程序+H5）
npm install
npm run dev:mp-weixin
```

### 打开编译后的项目

在微信开发者工具中打开：
```
私房菜点餐项目前端模版（微信小程序+H5）/unpackage/dist/dev/mp-weixin
```

## 开发建议

### 推荐工作流程

1. **使用 HBuilderX 开发**：
   - 代码提示更好
   - 编译更快
   - 集成度高

2. **使用微信开发者工具调试**：
   - 查看真实效果
   - 调试网络请求
   - 测试真机

### 文件修改后

- HBuilderX 会自动重新编译
- 微信开发者工具会自动刷新
- 无需手动操作

## 项目结构说明

```
私房菜点餐项目前端模版（微信小程序+H5）/
├── pages/              # 页面源码（Vue）
├── api/                # API 接口
├── utils/              # 工具函数
├── static/             # 静态资源
├── pages.json          # 页面配置（uni-app）
├── manifest.json       # 应用配置（uni-app）
└── unpackage/          # 编译输出目录
    └── dist/
        └── dev/
            └── mp-weixin/  # 微信小程序编译结果
                ├── app.json    # 这才是微信需要的
                ├── app.js
                └── pages/
```

## 总结

- ✅ **正确做法**：使用 HBuilderX 打开项目并运行
- ❌ **错误做法**：直接在微信开发者工具中打开源码目录
- 💡 **原理**：uni-app 需要编译成微信小程序代码才能运行
