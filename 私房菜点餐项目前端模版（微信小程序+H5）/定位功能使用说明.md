# 小程序定位功能使用说明

## 功能概述

已为小程序添加完整的定位功能，包括：

✅ 自动获取用户位置
✅ 显示到店距离
✅ 地图查看
✅ 导航到店
✅ 权限管理

## 功能展示

### 首页位置栏

在首页顶部显示：
```
📍 私房菜餐厅  距您 1.2公里
```

点击位置栏可以：
- 查看地图
- 导航到店
- 重新定位

## 配置餐厅位置

### 第一步：获取餐厅坐标

1. 打开腾讯位置服务：https://lbs.qq.com/getPoint/
2. 在搜索框输入你的餐厅地址
3. 点击搜索结果，地图会显示位置
4. 复制显示的经纬度坐标

### 第二步：修改配置文件

打开文件：`config/restaurant.js`

修改以下内容：

```javascript
export default {
	// 餐厅基本信息
	name: '你的餐厅名称',
	address: '你的餐厅地址',
	phone: '你的电话号码',
	
	// 餐厅位置坐标（必须填写）
	location: {
		latitude: 39.9042,   // 改成你的纬度
		longitude: 116.4074  // 改成你的经度
	},
	
	// 其他配置...
}
```

### 第三步：测试

1. 保存文件
2. 重新编译小程序
3. 在首页查看位置信息是否正确

## 功能详解

### 1. 自动定位

小程序启动时会自动：
1. 检查位置权限
2. 获取用户当前位置
3. 计算到店距离
4. 显示在首页顶部

### 2. 位置权限

如果用户未授权位置权限：
- 首次使用会弹出授权提示
- 拒绝后可以点击位置栏重新授权
- 会引导用户到设置页面开启权限

### 3. 查看地图

点击位置栏 → 选择"查看地图"：
- 打开系统地图
- 显示餐厅位置
- 可以查看周边环境

### 4. 导航到店

点击位置栏 → 选择"导航到店"：
- 可选择导航方式：
  - 系统地图（推荐）
  - 高德地图
  - 百度地图
- 自动规划路线
- 实时导航

### 5. 重新定位

如果位置不准确：
- 点击位置栏
- 选择"重新定位"
- 系统会重新获取位置

## 小程序配置

### manifest.json 配置

确保在 `manifest.json` 中配置了位置权限：

```json
{
  "mp-weixin": {
    "permission": {
      "scope.userLocation": {
        "desc": "您的位置信息将用于计算到店距离和导航"
      }
    }
  }
}
```

### 隐私协议

微信小程序需要在隐私协议中说明位置信息的使用：

1. 登录微信公众平台
2. 进入小程序管理后台
3. 设置 → 服务内容声明
4. 添加"位置信息"使用说明

## 常见问题

### Q1: 位置获取失败？

A: 可能原因：
1. 用户未授权位置权限
2. 手机GPS未开启
3. 网络问题

解决方法：
- 引导用户开启位置权限
- 检查手机GPS设置
- 检查网络连接

### Q2: 距离计算不准确？

A: 可能原因：
1. 餐厅坐标配置错误
2. 用户位置不准确

解决方法：
- 检查 `config/restaurant.js` 中的坐标
- 使用腾讯位置服务重新获取坐标
- 让用户重新定位

### Q3: 导航打不开？

A: 可能原因：
1. 手机未安装对应地图APP
2. 小程序权限不足

解决方法：
- 使用"系统地图"选项
- 安装对应的地图APP

### Q4: H5端如何使用？

A: H5端定位功能：
- 浏览器会请求位置权限
- 用户需要允许位置访问
- 部分浏览器可能不支持

## API 说明

### getUserLocation()

获取用户当前位置

```javascript
import { getUserLocation } from '@/utils/location.js'

getUserLocation().then(location => {
  console.log('纬度:', location.latitude)
  console.log('经度:', location.longitude)
})
```

### getDistanceToRestaurant(lat, lon)

计算到店距离

```javascript
import { getDistanceToRestaurant } from '@/utils/location.js'

const distance = getDistanceToRestaurant(39.9042, 116.4074)
console.log('距离:', distance.formatted) // "1.2公里"
```

### navigateToRestaurant(type)

导航到店

```javascript
import { navigateToRestaurant } from '@/utils/location.js'

// 系统地图
navigateToRestaurant('default')

// 高德地图
navigateToRestaurant('amap')

// 百度地图
navigateToRestaurant('baidu')
```

   - 快速选择地址

## 注意事项

1. **坐标系统**
   - 使用 GCJ-02 坐标系（国测局坐标）
   - 不要使用 GPS 原始坐标（WGS-84）

2. **隐私保护**
   - 不要保存用户精确位置
   - 只计算距离，不上传坐标

3. **性能优化**
   - 定位结果可以缓存
   - 避免频繁请求定位

4. **用户体验**
   - 定位失败要有友好提示
   - 提供手动输入地址的选项

## 测试建议

   - 开发工具的模拟定位不准确
