# 最简单的图片下载方案

## 方案说明

我理解你的需求：
- ❌ 不想手动重命名每张图片
- ❌ 不想一张一张保存
- ✅ 想要批量下载
- ✅ 自动命名

## 推荐方案：两步走

### 第一步：批量下载（随便命名）

1. 打开百度图片搜索页面（已生成）
2. 把所有图片下载到 `downloads` 文件夹
3. 文件名随便，不用管

### 第二步：自动重命名

运行脚本：
```bash
python auto_rename_images.py
```

脚本会：
1. 读取 downloads 文件夹中的所有图片
2. 逐个显示图片
3. 询问你："这是XXX菜吗？"
4. 你只需要输入 y(是) 或 n(否)
5. 脚本自动重命名并移动到正确位置

## 详细步骤

### 步骤1：创建下载文件夹

在项目根目录创建 `downloads` 文件夹：
```
私房菜点餐项目前端模版（微信小程序+H5）/
  └── downloads/          ← 创建这个文件夹
```

### 步骤2：批量下载图片

1. 打开 `baidu_image_download.html`
2. 点击"搜索图片"
3. 在百度图片中，右键保存图片到 `downloads` 文件夹
4. 文件名随便，比如：
   - 1.jpg
   - 2.jpg
   - 3.jpg
   - ...

### 步骤3：运行自动重命名脚本

```bash
python auto_rename_images.py
```

脚本会显示：
```
[1/69] 干煸芸豆 (gbyd.jpg)
   当前图片: 1.jpg
   这是 干煸芸豆 吗？(y=是/n=否/s=跳过):
```

你只需要输入：
- `y` - 是的，这就是干煸芸豆
- `n` - 不是，看下一张图片
- `s` - 跳过这道菜，稍后再处理

### 步骤4：完成

脚本会自动：
- 重命名图片为正确的文件名
- 移动到 `static/menu/menulist/` 目录
- 如果是PNG格式，自动转换为JPG

## 优势

✅ 下载时不用管文件名
✅ 不用手动重命名
✅ 不用手动移动文件
✅ 自动格式转换
✅ 可以随时中断，下次继续

## 更快的方法

如果你下载图片时能按顺序：

1. 按照菜品列表的顺序下载
2. 文件名用数字：1.jpg, 2.jpg, 3.jpg...
3. 运行脚本时，一路按 `y` 就行了

## 常见问题

### Q: 下载的图片格式不是JPG怎么办？

A: 没关系！脚本会自动转换PNG、WEBP等格式为JPG。

### Q: 中途想停止怎么办？

A: 按 Ctrl+C 停止。下次运行时，已处理的图片不会重复处理。

### Q: 搞错了怎么办？

A: 删除 `static/menu/menulist/` 中错误的图片，重新运行脚本。

### Q: 可以一次只处理几张吗？

A: 可以！下载几张就处理几张，剩下的稍后继续。

## 开始使用

1. 创建 `downloads` 文件夹
2. 下载图片到这个文件夹（文件名随便）
3. 运行 `python auto_rename_images.py`
4. 按提示操作

就这么简单！🎉
