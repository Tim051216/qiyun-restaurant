## 管理员操作指南

### 1. 生成桌号二维码

#### 1.1 访问管理后台
1. 打开管理后台页面（待开发）
2. 进入"桌号管理"模块

#### 1.2 生成二维码
1. 输入桌号（如：A01、B02）
   - 只能包含字母和数字
   - 长度限制：1-10 位
   - 建议格式：区域+编号（如：A01、B02）

2. 点击"生成二维码"按钮

3. 等待生成完成
   - 系统会自动生成小程序码
   - 上传到云存储
   - 保存到数据库

4. 查看生成结果
   - 显示小程序码图片
   - 显示桌号信息
   - 显示生成时间

#### 1.3 下载和打印
1. 点击"下载"按钮
   - 下载小程序码图片
   - 格式：PNG
   - 尺寸：430x430 像素

2. 打印二维码
   - 使用高质量打印机
   - 建议尺寸：5cm x 5cm 以上
   - 使用防水材料

3. 放置二维码
   - 贴在桌面显眼位置
   - 确保不被遮挡
   - 定期检查是否清晰

### 2. 管理桌号

#### 2.1 查看桌号列表
1. 在管理后台查看所有桌号
2. 显示信息：
   - 桌号
   - 二维码图片
   - 创建时间
   - 更新时间
   - 状态

#### 2.2 更新二维码
1. 选择需要更新的桌号
2. 点击"重新生成"
3. 系统会生成新的二维码
4. 旧的二维码仍然有效

#### 2.3 删除桌号
1. 选择需要删除的桌号
2. 点击"删除"按钮
3. 确认删除操作
4. 二维码将失效

### 3. 监控和维护

#### 3.1 查看错误日志
1. 在管理后台查看错误日志
2. 分析常见错误
3. 及时处理异常

#### 3.2 数据统计
1. 查看扫码次数
2. 查看使用频率
3. 分析用户行为

## 用户扫码流程

### 1. 扫码进入

#### 1.1 微信小程序
1. 打开微信
2. 扫描桌上的二维码
3. 自动打开小程序
4. 进入首页

#### 1.2 H5 页面
1. 使用浏览器扫描二维码
2. 自动跳转到 H5 页面
3. 进入首页

### 2. 确认桌号

#### 2.1 弹窗显示
扫码成功后，会自动弹出确认弹窗：
- 显示当前桌号
- 提示选择就餐人数
- 显示确认按钮

#### 2.2 选择人数
1. 点击"-"或"+"按钮
2. 调整就餐人数（1-20人）
3. 确认人数无误

#### 2.3 确认提交
1. 点击"确认"按钮
2. 系统保存桌号和人数
3. 弹窗自动关闭
4. 显示成功提示

### 3. 开始点餐

#### 3.1 浏览菜单
1. 点击"门店堂食"或"外卖派送"
2. 进入菜单页面
3. 浏览菜品分类
4. 查看菜品详情

#### 3.2 添加菜品
1. 选择喜欢的菜品
2. 点击"加入购物车"
3. 调整数量
4. 继续选择其他菜品

#### 3.3 查看购物车
1. 点击购物车图标
2. 查看已选菜品
3. 修改数量或删除
4. 查看总价

#### 3.4 提交订单
1. 点击"去结算"
2. 确认订单信息
3. 选择支付方式
4. 完成支付

### 4. 订单跟踪

#### 4.1 查看订单状态
1. 进入"我的订单"
2. 查看订单详情
3. 实时跟踪订单状态

#### 4.2 订单状态说明
- 待支付：等待用户支付
- 已支付：支付成功，等待商家确认
- 制作中：商家正在制作
- 已完成：订单完成

### 5. 其他功能

#### 5.1 AI 助手
1. 点击右下角的 AI 助手图标
2. 输入问题或需求
3. 获取智能推荐和帮助

#### 5.2 会员中心
1. 点击"会员中心"
2. 查看会员信息
3. 查看积分和优惠券
4. 参加会员活动

#### 5.3 活动中心
1. 点击"活动中心"
2. 查看当前活动
3. 参加限时秒杀
4. 领取优惠券

## 常见问题

### 用户端问题

#### Q1: 扫码后没有反应？
**A:** 可能的原因和解决方法：
1. 二维码损坏或模糊
   - 联系服务员更换二维码
2. 网络连接问题
   - 检查手机网络连接
   - 切换到 WiFi 或 4G/5G
3. 小程序版本过旧
   - 删除小程序重新扫码
   - 更新微信到最新版本

#### Q2: 弹窗没有显示？
**A:** 可能的原因和解决方法：
1. 已经确认过桌号
   - 桌号信息已保存，可以直接点餐
   - 如需更换桌号，清除小程序数据
2. 参数解析失败
   - 重新扫码
   - 联系服务员

#### Q3: 无法选择人数？
**A:** 可能的原因和解决方法：
1. 按钮无响应
   - 刷新页面重试
   - 重新扫码
2. 人数限制
   - 人数范围：1-20人
   - 如需更多人数，联系服务员

#### Q4: 确认后无法点餐？
**A:** 可能的原因和解决方法：
1. 保存失败
   - 检查网络连接
   - 重新确认桌号
2. 权限问题
   - 授予小程序必要权限
   - 重启小程序

#### Q5: 如何更换桌号？
**A:** 两种方法：
1. 清除数据
   - 长按小程序图标
   - 选择"删除"
   - 重新扫码
2. 重新扫码
   - 扫描新桌号的二维码
   - 系统会自动更新

#### Q6: 定位失败怎么办？
**A:** 解决方法：
1. 授予位置权限
   - 在手机设置中允许微信访问位置
   - 重新打开小程序
2. 手动输入位置
   - 点击位置栏
   - 选择"手动输入"
3. 跳过定位
   - 定位不是必需的
   - 可以直接开始点餐

### 管理员问题

#### Q1: 生成二维码失败？
**A:** 可能的原因和解决方法：
1. 网络问题
   - 检查网络连接
   - 重试生成
2. 桌号格式错误
   - 检查桌号格式（字母数字，1-10位）
   - 修改后重试
3. 云服务异常
   - 查看错误日志
   - 联系技术支持

#### Q2: 二维码无法下载？
**A:** 可能的原因和解决方法：
1. 浏览器限制
   - 允许浏览器下载文件
   - 更换浏览器重试
2. 云存储问题
   - 检查云存储配置
   - 查看错误日志

#### Q3: 桌号重复怎么办？
**A:** 处理方法：
1. 系统会自动更新
   - 相同桌号会更新二维码
   - 旧的二维码仍然有效
2. 建议使用唯一桌号
   - 使用区域+编号格式
   - 避免重复

#### Q4: 如何批量生成？
**A:** 当前版本不支持批量生成，需要：
1. 逐个生成桌号
2. 或联系技术支持开发批量功能

## 技术说明

### 1. 系统架构

#### 1.1 前端
- uni-app 框架
- 支持微信小程序和 H5
- 响应式设计

#### 1.2 云端
- uniCloud 云服务
- 云对象：table-qrcode
- 云数据库：tables、error_logs
- 云存储：qrcodes

#### 1.3 微信接口
- 小程序码生成 API
- access_token 管理
- 场景值参数传递

### 2. 数据流程

#### 2.1 生成流程
```
管理员输入桌号
    ↓
调用云对象 generateQRCode
    ↓
获取 access_token
    ↓
调用微信 API 生成小程序码
    ↓
上传到云存储
    ↓
保存到数据库
    ↓
返回结果
```

#### 2.2 扫码流程
```
用户扫描二维码
    ↓
小程序启动，解析 scene 参数
    ↓
提取桌号信息
    ↓
显示确认弹窗
    ↓
用户选择人数并确认
    ↓
保存到本地存储
    ↓
开始点餐
```

### 3. 本地存储

#### 3.1 存储内容
- tableNumber：桌号
- dinerCount：就餐人数
- scanTime：扫码时间

#### 3.2 存储时机
- 用户确认桌号后
- 自动保存到本地

#### 3.3 存储有效期
- 永久有效（除非用户清除）
- 可以跨会话使用

### 4. 错误处理

#### 4.1 错误类型
- 网络超时
- 无效参数
- 存储失败
- 位置权限被拒绝

#### 4.2 错误提示
- 友好的中文提示
- 提供重试选项
- 引导用户操作

#### 4.3 错误上报
- 关键错误自动上报到云端
- 记录错误日志
- 便于问题排查

### 5. 性能优化

#### 5.1 缓存策略
- access_token 缓存（2小时）
- 本地存储缓存
- 图片懒加载

#### 5.2 防抖节流
- 确认按钮防抖（1秒）
- 避免重复提交

#### 5.3 图片优化
- 小程序码压缩
- 懒加载技术
- CDN 加速

### 6. 安全措施

#### 6.1 参数验证
- 桌号格式验证
- 人数范围验证
- 防止恶意输入

#### 6.2 权限控制
- 云对象访问控制
- 数据库权限设置
- 敏感信息保护

#### 6.3 错误日志
- 记录关键操作
- 监控异常行为
- 定期清理日志
