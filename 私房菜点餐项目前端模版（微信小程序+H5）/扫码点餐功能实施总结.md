## 页面集成

### 首页 (pages/index/index.vue)

**已更新功能:**
- ✅ 使用 `handleLaunchParams()` 处理启动参数
- ✅ 使用 `getTableInfo()` 获取桌号信息
- ✅ 使用 `saveTableInfo()` 保存桌号信息
- ✅ 添加 `onShow()` 生命周期检查弹窗显示
- ✅ 优化桌号确认弹窗逻辑

**代码示例:**
```javascript
import { handleLaunchParams, getTableInfo, saveTableInfo } from '@/utils/launchParams.js'

onLoad(options) {
  const tableInfo = getTableInfo(options)
  if (tableInfo.tableNumber && tableInfo.fromScan) {
    this.tableNumber = tableInfo.tableNumber
    this.showTableDialog = true
  }
}

confirmTable() {
  saveTableInfo(this.tableNumber, this.dinerCount)
  this.showTableDialog = false
}
```

### 扫码点餐页 (pages/scan-order/scan-order.vue)

**已更新功能:**
- ✅ 使用 `getTableInfo()` 获取桌号
- ✅ 添加桌号验证逻辑
- ✅ 无桌号时自动跳转首页

**代码示例:**
```javascript
import { getTableInfo } from '@/utils/launchParams.js'

onLoad(options) {
  const tableInfo = getTableInfo(options)
  if (tableInfo.tableNumber) {
    this.tableNo = tableInfo.tableNumber
  } else {
    uni.showToast({ title: '请先扫码获取桌号', icon: 'none' })
    setTimeout(() => {
      uni.switchTab({ url: '/pages/index/index' })
    }, 1500)
  }
}
```

## 技术亮点

### 1. 跨平台兼容

使用条件编译实现小程序和 H5 的完美兼容:

```javascript
// #ifdef MP-WEIXIN
return 'mp-weixin'
// #endif

// #ifdef H5
return 'h5'
// #endif
```

### 2. 统一接口设计

所有工具都提供统一的接口,降低使用复杂度:

```javascript
// 存储操作
StorageAdapter.set(key, value)
StorageAdapter.get(key)

// 导航操作
NavigationAdapter.navigateTo(url)
NavigationAdapter.switchTab(url)
```

### 3. 业务场景封装

针对常见业务场景提供专门的封装:

```javascript
// 桌号管理
TableStorage.save('A01', 4)
const tableInfo = TableStorage.get()

// 购物车管理
CartStorage.addItem(item)
CartStorage.updateItemCount(itemId, count)
```

### 4. 状态管理

提供完整的状态管理方案,支持状态监听:

```javascript
// 设置状态
setTableState('A01', 4)

// 监听状态变化
addListener('table', (tableState) => {
  console.log('桌号状态变化:', tableState)
})
```

### 5. 错误处理

所有操作都包含完善的错误处理和日志记录:

```javascript
try {
  const success = saveToLocalStorage(key, value)
  if (success) {
    console.log('[LocalStorage] 保存成功')
  }
} catch (error) {
  console.error('[LocalStorage] 保存失败:', error)
}
```
