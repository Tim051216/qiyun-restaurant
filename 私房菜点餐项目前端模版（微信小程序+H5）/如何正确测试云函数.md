# 如何正确测试云函数

## 🔴 你当前的问题

日志显示：
```
云函数开始执行，接收参数: {}  ← 参数是空的！
参数验证失败：消息为空
```

**原因：** 你运行了云函数，但没有在测试窗口中输入参数。

---

## ✅ 正确的测试步骤

### 方法 1：使用 HBuilderX 测试窗口

#### 步骤 1：打开测试窗口

1. 右键点击 `ai-chat` 云函数目录
2. 选择 **"运行-本地云函数"** 或 **"运行-云端云函数"**
3. 会弹出一个测试窗口

#### 步骤 2：在测试窗口中输入参数

**重要：** 在测试窗口的**参数输入框**中，输入以下 JSON：

```json
{
  "message": "你好",
  "history": []
}
```

**注意：**
- 必须是有效的 JSON 格式
- 不要有多余的空格或换行
- 确保引号是英文引号

#### 步骤 3：点击运行按钮

点击测试窗口中的 **"运行"** 按钮。

#### 步骤 4：查看结果

**成功的日志应该是：**
```
云函数开始执行，接收参数: {message: "你好", history: []}
开始构建请求...
消息列表: [...]
开始调用通义千问 API...
API 响应状态: 200
AI 回复成功: 你好！我是七云菜馆的AI点餐助手...
```

**返回结果应该是：**
```json
{
  "code": 200,
  "success": true,
  "message": "你好！我是七云菜馆的AI点餐助手...",
  "usage": {...}
}
```

---

### 方法 2：使用 uniCloud 控制台测试（更简单）

如果 HBuilderX 的测试窗口不好用，可以用控制台：

#### 步骤 1：打开控制台

1. 访问 https://unicloud.dcloud.net.cn/
2. 登录你的账号
3. 选择服务空间 "demo"

#### 步骤 2：找到云函数

1. 点击左侧 **"云函数/云对象"**
2. 找到 `ai-chat` 云函数
3. 点击进入详情页

#### 步骤 3：在线测试

1. 点击 **"测试"** 标签
2. 在测试参数框中输入：

```json
{
  "message": "你好",
  "history": []
}
```

3. 点击 **"运行"** 按钮
4. 查看返回结果

#### 步骤 4：查看日志

点击 **"日志"** 标签，可以看到详细的执行日志。

---

### 方法 3：直接在小程序中测试（跳过云函数测试）

如果云函数已经上传成功，可以直接在小程序中测试：

#### 步骤 1：确认云函数已上传

在 HBuilderX 中，`ai-chat` 云函数目录应该有一个云图标，表示已上传。

#### 步骤 2：重启小程序

1. 在微信开发者工具中：清除缓存
2. 在 HBuilderX 中：停止运行 → 重新运行

#### 步骤 3：测试 AI 助手

1. 在小程序首页点击右下角 🤖 按钮
2. 输入 "你好"
3. 查看是否有回复

#### 步骤 4：查看日志

在微信开发者工具控制台中，应该能看到：

```
[AI] 开始调用，消息: 你好
云函数开始执行，接收参数: {message: "你好", history: []}
开始构建请求...
开始调用通义千问 API...
API 响应状态: 200
AI 回复成功: ...
[AI] 调用成功
```

---

## 🎯 推荐方案

**我建议你直接使用方法 3：在小程序中测试**

1. 云函数已经上传成功了
2. 代码没有问题（只是测试参数没传对）
