# 手机号授权问题排查

## 问题现象
点击"手机号快捷登录"按钮后，没有弹出授权弹窗，直接返回 `getPhoneNumber:fail`

## 可能的原因

### 1. 小程序未开通手机号权限（最常见）

**检查方法：**
1. 登录微信公众平台：https://mp.weixin.qq.com
2. 进入小程序管理后台
3. 开发 -> 开发管理 -> 接口设置
4. 查找"手机号快速验证"或"手机号实时验证"
5. 检查是否已开通

**解决方法：**
- 点击"开通"按钮
- 需要小程序已认证（个人小程序不支持）
- 需要非个人主体

### 2. 小程序主体类型不符合要求

**要求：**
- 必须是企业、政府、媒体、其他组织类型
- 必须完成微信认证
- 个人小程序不支持此功能

**检查方法：**
1. 微信公众平台 -> 设置 -> 基本设置
2. 查看"主体信息"
3. 查看"微信认证"状态

### 3. 在开发工具中测试

**问题：**
- 微信开发者工具可能不完全支持手机号授权
- 某些版本的开发工具有 bug

**解决方法：**
- 使用真机调试
- 或者使用体验版/正式版测试
- 不要只在开发工具中测试

### 4. 基础库版本过低

**要求：**
- 基础库版本 >= 2.21.2（新版 API）
- 或 >= 1.2.0（旧版 API）

**检查方法：**
1. 微信开发者工具 -> 详情 -> 本地设置
2. 查看"调试基础库"版本
3. 建议使用最新版本

### 5. AppID 配置错误

**检查：**
- project.config.json 中的 appid 是否正确
- 是否使用了测试号（测试号不支持）

## 详细排查步骤

### 步骤 1：查看完整错误信息

修改代码，打印完整的错误信息：
```javascript
handlePhoneLogin(e) {
  console.log('完整回调:', JSON.stringify(e.detail))
  console.log('errMsg:', e.detail.errMsg)
  console.log('errno:', e.detail.errno)
}
```

### 步骤 2：常见错误码

| errMsg | 含义 | 解决方法 |
|--------|------|----------|
| `getPhoneNumber:fail` | 通用失败 | 查看具体原因 |
| `getPhoneNumber:fail scope unauthorized` | 未开通权限 | 去公众平台开通 |
| `getPhoneNumber:fail user deny` | 用户拒绝 | 引导用户同意 |
| `getPhoneNumber:fail system error` | 系统错误 | 稍后重试 |
| `getPhoneNumber:fail:1400001` | 额度不足 | 购买资源包 |

### 步骤 3：检查小程序配置

**project.config.json:**
```json
{
  "appid": "你的真实AppID",  // 不能是测试号
  "miniprogramRoot": "./",
  "setting": {
    "urlCheck": false,
    "es6": true,
    "enhance": true,
    "postcss": true,
    "minified": true
  }
}
```

### 步骤 4：检查按钮配置

**正确的按钮配置：**
```vue
<button 
  class="phone-login-btn" 
  open-type="getPhoneNumber" 
  @getphonenumber="handlePhoneLogin"
>
  手机号快捷登录
</button>
```

**注意：**
- `open-type` 必须是 `getPhoneNumber`（注意大小写）
- 事件名是 `@getphonenumber`（全小写）
- 必须是 `<button>` 标签，不能是其他标签

## 开发工具测试限制

### 开发工具可能的问题：
1. 不弹出授权弹窗
2. 直接返回失败
3. 返回的 code 无效

### 建议的测试方式：
1. **真机调试**（最推荐）
   - 微信开发者工具 -> 预览 -> 真机调试
   - 使用真实手机扫码测试

2. **体验版**
   - 上传代码为体验版
   - 添加体验成员
   - 在手机上打开体验版测试

3. **正式版**
   - 提交审核并发布
   - 在正式版中测试

## 替代方案

如果手机号授权功能无法使用，可以考虑：

### 方案 1：手机号 + 验证码登录
```vue
<input type="number" placeholder="请输入手机号" />
<button @click="sendCode">发送验证码</button>
<input type="number" placeholder="请输入验证码" />
<button @click="login">登录</button>
```

### 方案 2：微信授权登录（不获取手机号）
```vue
<button open-type="getUserProfile" @getuserinfo="handleUserInfo">
  微信授权登录
</button>
```

### 方案 3：游客模式
- 允许用户先浏览
- 需要下单时再要求登录
- 提供多种登录方式选择

## 常见问题 FAQ

### Q1: 为什么开发工具中不弹窗？
A: 开发工具可能不完全支持，请使用真机调试。

### Q2: 个人小程序能用吗？
A: 不能，必须是企业等非个人主体且已认证。

### Q3: 测试号能用吗？
A: 不能，必须使用真实的 AppID。

### Q4: 如何知道是否开通了权限？
A: 登录公众平台 -> 开发 -> 接口设置 -> 查看"手机号快速验证"状态。

### Q5: 用户拒绝授权怎么办？
A: 引导用户重新点击，或提供其他登录方式。

### Q6: 额度用完了怎么办？
A: 购买资源包，或等待下个月重置（如果有月度套餐）。

## 调试技巧

### 1. 打印详细日志
```javascript
handlePhoneLogin(e) {
  console.log('=== 手机号授权回调 ===')
  console.log('errMsg:', e.detail.errMsg)
  console.log('code:', e.detail.code)
  console.log('errno:', e.detail.errno)
  console.log('完整 detail:', JSON.stringify(e.detail))
  console.log('=====================')
}
```

### 2. 使用 vconsole
在 index.html 中引入：
```html
<script src="https://cdn.jsdelivr.net/npm/vconsole"></script>
<script>
  var vConsole = new VConsole();
</script>
```

### 3. 查看网络请求
- 微信开发者工具 -> Network
- 查看是否有相关的 API 请求
- 检查请求和响应
