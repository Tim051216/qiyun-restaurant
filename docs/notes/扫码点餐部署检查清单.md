# 扫码点餐部署检查清单

## 📋 快速检查清单

### ☐ 第一步：创建云服务空间（5分钟）
```
1. 右键 uniCloud-aliyun → 创建云服务空间
2. 选择阿里云
3. 输入名称：qiyun-restaurant
4. 等待创建完成
```

### ☐ 第二步：配置微信凭证（5分钟）
```
1. 右键 uniCloud-aliyun → 打开 Web 控制台
2. 云函数/云对象 → 公共模块或扩展库 → uni-open-bridge
3. 添加配置：
   {
     "mp-weixin": {
       "appid": "wxc63d199886077877",
       "appsecret": "e51393d39a5e8515bc97542eca91f74b"
     }
   }
4. 保存
```

### ☐ 第三步：创建数据库集合（10分钟）
```
1. Web 控制台 → 云数据库 → 新建集合

2. 创建 zhuohao 集合
   - 索引：table_number（唯一索引）

3. 创建 token_cache 集合
   - 索引：cache_key（唯一索引）

4. 创建 error_logs 集合
   - 无需索引
```

### ☐ 第四步：配置云存储（5分钟）
```
1. Web 控制台 → 云存储 → 新建目录
2. 目录名称：qrcodes
3. 权限：所有用户可读
```

### ☐ 第五步：上传云对象（5分钟）
```
1. 右键 zhuohao 云对象 → 上传部署
2. 等待上传完成
```

### ☐ 第六步：测试云对象（5分钟）
```
1. 右键 zhuohao → 运行-云端测试
2. 输入：
   {
     "method": "generateQRCode",
     "params": ["测试桌1"]
   }
3. 运行，检查返回 success: true
```

### ☐ 第七步：配置域名白名单（5分钟）
```
1. 复制云存储域名（在云存储页面顶部）
2. 登录微信公众平台
3. 开发 → 开发管理 → 开发设置 → 服务器域名
4. 在 downloadFile 合法域名中添加云存储域名
5. 保存
```

### ☐ 第八步：小程序测试（5分钟）
```
1. 运行到微信开发者工具
2. 添加编译模式：scene=测试桌1
3. 编译，检查弹窗显示
4. 测试完整流程
```

## 🚨 遇到问题？

### 快速诊断

**问题 1：上传云对象失败**
→ 检查网络 → 确认已登录 → 重启 HBuilderX

**问题 2：生成小程序码失败**
→ 检查微信凭证 → 查看云函数日志 → 确认 uni-open-bridge 配置

**问题 3：图片无法显示**
→ 检查域名白名单 → 确认云存储域名 → 查看网络请求

**问题 4：数据库操作失败**
→ 检查集合是否创建 → 确认索引设置 → 查看云函数日志
