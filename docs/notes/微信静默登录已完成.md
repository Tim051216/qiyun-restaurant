## 登录流程

```
用户打开小程序
    ↓
App.vue 检查登录状态
    ↓ (未登录)
跳转到登录页
    ↓
用户点击"微信一键登录"
    ↓
调用 uni.login() 获取 code
    ↓
发送 code 到后端
    ↓
后端调用微信API获取 openid
    ↓
后端查询/创建会员
    ↓
后端返回 token 和会员信息
    ↓
前端保存 token 和用户信息
    ↓
跳转到首页
    ↓
登录成功!
```

## 注意事项

### 测试号限制
- ✅ 支持基本登录(获取openid)
- ❌ 不支持获取手机号
- ❌ 不支持微信支付
- ❌ 不支持部分高级API

### 静默登录的优势
1. **无需用户授权** - 直接获取openid,用户无感知
2. **体验流畅** - 一键登录,无需额外操作
3. **安全可靠** - 使用微信官方接口
4. **符合规范** - 符合微信小程序最新规范

### 与传统登录的区别
- **传统方式**: 需要用户点击授权按钮,获取用户信息
- **静默登录**: 直接获取openid,不需要用户授权
- **推荐使用**: 静默登录(当前实现)

## 数据库表

会员信息存储在 `member` 表:
```sql
CREATE TABLE member (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  openid VARCHAR(100) UNIQUE,  -- 微信openid
  nickname VARCHAR(50),         -- 昵称
  avatar VARCHAR(255),          -- 头像
  phone VARCHAR(20),            -- 手机号
  level VARCHAR(20),            -- 会员等级
  points INT DEFAULT 0,         -- 积分
  balance DECIMAL(10,2),        -- 余额
  total_consume DECIMAL(10,2),  -- 总消费
  order_count INT DEFAULT 0,    -- 订单数
  status INT DEFAULT 1,         -- 状态
  create_time DATETIME,         -- 创建时间
  update_time DATETIME,         -- 更新时间
  deleted INT DEFAULT 0         -- 删除标记
);
```
