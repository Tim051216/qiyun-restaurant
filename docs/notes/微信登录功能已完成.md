## 登录流程

```
1. 用户打开小程序
   ↓
2. App.vue 检查是否有token
   ↓ (无token)
3. 跳转到登录页 /pages/login/login
   ↓
4. 用户点击"微信一键登录"
   ↓
5. 前端调用 uni.login() 获取临时code
   ↓
6. 前端发送 code 到后端 POST /wechat/login
   ↓
7. 后端调用微信API: code → openid
   ↓
8. 后端查询数据库: openid → member
   ↓ (不存在则创建新会员)
9. 后端生成token并返回
   ↓
10. 前端保存token到storage
   ↓
11. 跳转到首页,登录成功!
```

## 数据库表结构

使用 `member` 表存储会员信息:

```sql
- id: 会员ID (主键,自增)
- openid: 微信openid (唯一标识)
- nickname: 昵称
- avatar: 头像
- phone: 手机号
- level: 会员等级
- points: 积分
- balance: 余额
- total_consume: 总消费
- order_count: 订单数
- status: 状态
- create_time: 创建时间
- update_time: 更新时间
- deleted: 删除标记
```
