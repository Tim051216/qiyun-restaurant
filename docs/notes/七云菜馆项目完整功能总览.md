## 🎯 项目概述

**七云菜馆** 是一个基于微服务架构的全栈餐厅点餐管理系统，包含：
- 微信小程序 + H5（顾客端）
- Vue3 管理后台（商家端）
- Spring Cloud 微服务后端（5个服务）
