## 执行步骤

### 第一步: 下载 JMeter

1. 访问: https://jmeter.apache.org/download_jmeter.cgi
2. 下载: `apache-jmeter-5.6.3.zip` (约 70MB)
3. 解压到: `C:\apache-jmeter-5.6.3\`

### 第二步: 启动后端服务

```powershell
# 在项目根目录执行
.\启动所有服务.ps1
```

**注意**: 需要先启动 Docker Desktop

### 第三步: 执行压测

```powershell
# 进入压测目录
cd performance-test

# 执行压测
.\run-test.ps1
```
