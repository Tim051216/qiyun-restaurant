### 3. 如何保证分布式事务？

**方案：Seata AT模式**

```java
@GlobalTransactional
public void createOrder(OrderDTO dto) {
    // 1. 创建订单
    orderService.create(dto);
    // 2. 扣减库存
    dishService.deductStock(dto.getDishId());
    // 3. 扣减积分
    memberService.deductPoints(dto.getMemberId());
}
```

**原理：**
- 一阶段：执行业务SQL，记录undo log
- 二阶段：提交或回滚
- 如果失败，根据undo log回滚

### 4. 秒杀系统如何设计？

**完整方案：**

```
用户请求
  ↓
前端防重（按钮置灰）
  ↓
网关限流（Sentinel QPS=1000）
  ↓
Redis预减库存（DECR）
  ↓
消息队列（削峰填谷）
  ↓
分布式锁（Redisson）
  ↓
数据库扣库存
```

**关键代码：**
```java
// 1. Redis预减库存
Long stock = redisTemplate.opsForValue().decrement("stock:" + dishId);
if (stock < 0) {
    return Result.error("库存不足");
}

// 2. 发送MQ
rabbitTemplate.convertAndSend("seckill.exchange", "seckill.create", orderDTO);

// 3. 消费者处理（加分布式锁）
RLock lock = redissonClient.getLock("seckill:lock:" + dishId);
try {
    if (lock.tryLock(3, 10, TimeUnit.SECONDS)) {
        // 扣减数据库库存
        dishMapper.deductStock(dishId);
        // 创建订单
        orderMapper.insert(order);
    }
} finally {
    lock.unlock();
}
```

### 5. 缓存穿透、击穿、雪崩如何解决？

| 问题 | 原因 | 解决方案 | 代码示例 |
|------|------|---------|---------|
| **穿透** | 查询不存在的数据 | 布隆过滤器 + 空值缓存 | `bloomFilter.mightContain(key)` |
| **击穿** | 热点key过期 | 分布式锁 + 永不过期 | `lock.tryLock()` |
| **雪崩** | 大量key同时过期 | 过期时间随机 + 多级缓存 | `expire + random(300)` |

**布隆过滤器示例：**
```java
@PostConstruct
public void initBloomFilter() {
    List<Long> dishIds = dishMapper.selectAllIds();
    dishIds.forEach(id -> bloomFilter.put(id));
}

public Dish getById(Long id) {
    // 先查布隆过滤器
    if (!bloomFilter.mightContain(id)) {
        return null; // 一定不存在
    }
    // 再查缓存和数据库
    return queryFromCacheOrDB(id);
}
```

### 6. 如何保证消息不丢失？

**三个环节：**

1. **生产者 → MQ**
```java
rabbitTemplate.setConfirmCallback((correlationData, ack, cause) -> {
    if (!ack) {
        // 消息发送失败，重试或记录
        log.error("消息发送失败: {}", cause);
    }
});
```

2. **MQ持久化**
```java
@Bean
public Queue orderQueue() {
    return QueueBuilder.durable("order.queue").build();
}
```

3. **MQ → 消费者**
```java
@RabbitListener(queues = "order.queue", ackMode = "MANUAL")
public void handleOrder(Message message, Channel channel) {
    try {
        // 处理业务
        processOrder(message);
        // 手动ACK
        channel.basicAck(message.getMessageProperties().getDeliveryTag(), false);
    } catch (Exception e) {
        // 拒绝消息，重新入队
        channel.basicNack(message.getMessageProperties().getDeliveryTag(), false, true);
    }
}
```

### 7. 如何处理消息重复消费？

**方案：幂等性设计**

```java
@Transactional
public void processOrder(OrderDTO dto) {
    String idempotentKey = "order:idempotent:" + dto.getOrderNo();
    
    // 使用Redis SETNX实现幂等
    Boolean success = redisTemplate.opsForValue()
        .setIfAbsent(idempotentKey, "1", 24, TimeUnit.HOURS);
    
    if (Boolean.FALSE.equals(success)) {
        log.warn("订单已处理: {}", dto.getOrderNo());
        return; // 已处理过，直接返回
    }
    
    // 处理订单
    orderMapper.insert(order);
}
```

### 8. 分布式锁如何实现？

**Redisson实现：**

```java
public void deductStock(Long dishId) {
    String lockKey = "stock:lock:" + dishId;
    RLock lock = redissonClient.getLock(lockKey);
    
    try {
        // 尝试加锁：等待3秒，锁10秒后自动释放
        if (lock.tryLock(3, 10, TimeUnit.SECONDS)) {
            // 查询库存
            Integer stock = dishMapper.getStock(dishId);
            if (stock > 0) {
                // 扣减库存
                dishMapper.deductStock(dishId);
            }
        }
    } catch (InterruptedException e) {
        Thread.currentThread().interrupt();
    } finally {
        // 释放锁
        if (lock.isHeldByCurrentThread()) {
            lock.unlock();
        }
    }
}
```

**为什么用Redisson而不是SETNX？**
- 自动续期（看门狗机制）
- 可重入锁
- 公平锁/非公平锁
- 读写锁
- 红锁（RedLock）

```

  ↓

  ↓
存储层：Prometheus存储
```

- **MQ**: 消息堆积、消费速率

### 10. 如何优化接口性能？

**优化手段：**

1. **数据库优化**
   - 索引优化：覆盖索引、联合索引
   - SQL优化：避免全表扫描
   - 读写分离：主库写，从库读
   - 分库分表：单表<500万

2. **缓存优化**
   - 本地缓存：Caffeine，<1ms
   - Redis缓存：分布式，<10ms
   - 缓存预热：启动时加载热点数据

3. **异步处理**
   - MQ异步：下单后立即返回
   - CompletableFuture：并行查询

4. **代码优化**
   - 批量操作：批量插入、批量查询
   - 连接池：数据库连接池、HTTP连接池
   - 对象复用：ThreadLocal、对象池

**示例：**
```java
// 优化前：串行查询，耗时300ms
Dish dish = dishService.getById(dishId);           // 100ms
Member member = memberService.getById(memberId);   // 100ms
Coupon coupon = couponService.getById(couponId);   // 100ms

// 优化后：并行查询，耗时100ms
CompletableFuture<Dish> dishFuture = 
    CompletableFuture.supplyAsync(() -> dishService.getById(dishId));
CompletableFuture<Member> memberFuture = 
    CompletableFuture.supplyAsync(() -> memberService.getById(memberId));
CompletableFuture<Coupon> couponFuture = 
    CompletableFuture.supplyAsync(() -> couponService.getById(couponId));

CompletableFuture.allOf(dishFuture, memberFuture, couponFuture).join();
```
