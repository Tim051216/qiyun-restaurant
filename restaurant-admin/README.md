# 七云菜馆 - 商家后台管理系统

基于 Vue 3 + Vite + Element Plus 开发的现代化餐饮管理后台系统。

## 功能特性

### 核心功能
- 📊 **数据概览** - 实时查看今日订单、销售额、会员等关键数据
- 📋 **订单管理** - 订单列表、实时订单监控、订单处理
- 🍜 **菜品管理** - 菜品列表、分类管理、库存管理
- 🪑 **桌台管理** - 桌台状态监控、桌台信息管理
- 🎁 **营销管理** - 优惠券、活动、秒杀管理
- 👥 **会员管理** - 会员列表、等级管理
- 📈 **数据统计** - 销售统计、菜品统计
- ⚙️ **系统设置** - 基本设置、员工管理

### 技术栈
- Vue 3 - 渐进式 JavaScript 框架
- Vite - 下一代前端构建工具
- Element Plus - Vue 3 组件库
- Vue Router - 官方路由管理器
- Pinia - Vue 状态管理
- ECharts - 数据可视化图表库
- Axios - HTTP 客户端

## 快速开始

### 安装依赖
```bash
cd restaurant-admin
npm install
```

### 开发模式
```bash
npm run dev
```

访问 http://localhost:3000

### 生产构建
```bash
npm run build
```

### 预览构建结果
```bash
npm run preview
```

## 主要页面

### 数据概览
- 今日订单、销售额、新增会员等关键指标
- 销售趋势图表
- 菜品销量 TOP5
- 实时订单列表

### 订单管理
- 订单列表：查询、筛选、查看订单详情
- 实时订单：实时监控新订单，快速接单处理

### 菜品管理
- 菜品列表：添加、编辑、删除菜品，管理库存
- 分类管理：管理菜品分类

### 桌台管理
- 桌台状态监控：实时查看桌台使用情况
- 桌台信息管理：添加、编辑桌台信息

### 营销管理
- 优惠券管理：创建和管理优惠券
- 活动管理：管理营销活动
- 秒杀管理：设置秒杀活动

### 会员管理
- 会员列表：查看和管理会员信息
- 等级管理：设置会员等级和权益

### 数据统计
- 销售统计：查看销售趋势和排行
- 菜品统计：分析菜品销量

### 系统设置
- 基本设置：餐厅基本信息配置
- 员工管理：管理员工账号

## 开发说明

### 添加新页面
1. 在 `src/views/` 下创建页面组件
2. 在 `src/router/index.js` 中添加路由配置
3. 在侧边栏菜单中添加对应的导航项

### 样式规范
- 使用 SCSS 预处理器
- 遵循 BEM 命名规范
- 使用 Element Plus 主题变量

### 代码规范
- 使用 Vue 3 Composition API
- 使用 ESLint 进行代码检查
- 遵循 Vue 官方风格指南

## 注意事项

1. 本项目为前端演示项目，数据为模拟数据
2. 实际使用需要对接后端 API
3. 建议使用 Chrome 或 Edge 浏览器访问
